Rozdział CSS: Box model

Każdy element HTML jest prostokątnym pudełkiem. Box model to zestaw właściwości, które określają rozmiary, odstępy wewnętrzne i zewnętrzne oraz obramowanie. To absolutna podstawa układania stron.

1. Czym jest Box model?

Model pudełkowy składa się z czterech warstw (od środka na zewnątrz):

  • Content - właściwa treść (tekst, obrazek)
  • Padding - wewnętrzny odstęp między treścią a obramowaniem
  • Border - obramowanie
  • Margin - zewnętrzny odstęp od innych elementów

2. Szerokość i wysokość - width / height

Domyślnie width i height dotyczą wyłącznie contentu (bez paddingu, bordera i marginesu). 

.box {
    width: 200px;
    height: 100px;
}

Jednostki: px, %, vw, vh, auto, min-content, max-content.

WartośćOpis
autodomyślnie - element rozciąga się na dostępną szerokość

3. Padding - wewnętrzny odstęp

Padding powiększa tło elementu i oddala treść od krawędzi. 

.karta {
    padding: 20px;           /* wszystkie strony 20px */
    padding: 10px 20px;      /* góra/dół 10px, lewo/prawo 20px */
    padding: 5px 10px 15px 20px; /* góra, prawo, dół, lewo (zgodnie z zegarem) */
}

/* osobne właściwości */
.karta {
    padding-top: 10px;
    padding-right: 15px;
    padding-bottom: 10px;
    padding-left: 15px;
}

Ważne: Padding dodaje się do szerokości elementu - jeśli width: 200px i padding: 20px, całkowita szerokość wyniesie 240px (chyba że użyjemy box-sizing: border-box).

4. Margin - zewnętrzny odstęp

Margin oddala element od innych elementów. Nie ma tła ani obramowania. 

.odstep {
    margin: 20px;            /* wszystkie strony */
    margin: 10px 30px;       /* góra/dół 10px, lewo/prawo 30px */
    margin: 5px 10px 15px 20px; /* góra, prawo, dół, lewo */
}

/* osobne */
.odstep {
    margin-top: 10px;
    margin-right: 15px;
    margin-bottom: 10px;
    margin-left: 15px;
}

Zjawisko „margin collapse” - pionowe marginesy sąsiadujących elementów nakładają się (wybiera się większy).

/* przykład: dwa akapity z margin-bottom: 20px i margin-top: 30px */
/* odstęp między nimi wyniesie 30px, nie 50px */

5. Border - obramowanie

Border to linia wokół paddingu (lub contentu, jeśli brak paddingu). 

.ramka {
    border: 2px solid black;          /* grubość, styl, kolor */
    border: 3px dotted red;
    border: 1px dashed #2f7a67;
}

/* osobne właściwości */
.ramka {
    border-width: 2px;
    border-style: solid;
    border-color: navy;
}

/* tylko jedna krawędź */
.ramka {
    border-bottom: 1px solid gray;
}

6. box-sizing - klucz do opanowania wymiarów

Właściwość box-sizing zmienia sposób, w jaki przeglądarka oblicza całkowitą szerokość i wysokość elementu. 

/* Domyślne (content-box) - width = tylko treść */
.box1 {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    /* całkowita szerokość = 200 + 40 + 4 = 244px */
}

/* Border-box - width zawiera padding i border */
.box2 {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    /* całkowita szerokość = 200px (padding i border w środku) */
}
box-sizingJak działa width?Kiedy używać?
content-boxwidth tylko treści; padding i border dodają sięrzadziej, tradycyjny model
border-boxwidth = treść + padding + borderzdecydowanie częściej - łatwiejsze układanie

Globalny reset box-sizing - często spotykany w arkuszach: 

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

Dzięki temu wszystkie elementy używają border-box, a podawanie width staje się intuicyjne.

7. Obliczanie całkowitego rozmiaru - porównanie

/* content-box */
width = 300px
padding = 20px (lewo + prawo = 40px)
border = 5px (lewo + prawo = 10px)
margin = 15px (lewo + prawo = 30px)

Całkowita szerokość zajmowana = 300 + 40 + 10 + 30 = 380px
Szerokość elementu (widoczna) = 300 + 40 + 10 = 350px

/* border-box */
width = 300px (zawiera padding i border)
padding = 20px (lewo + prawo = 40px)
border = 5px (lewo + prawo = 10px)
margin = 15px (lewo + prawo = 30px)

Całkowita szerokość zajmowana = 300 + 30 = 330px
Szerokość treści = 300 - 40 - 10 = 250px

Na egzaminie INF03 często pojawia się pytanie: „Jaką szerokość zajmie element?” Sprawdź, czy użyto box-sizing.

8. Przykład - karta z box model

.card {
    box-sizing: border-box;
    width: 300px;
    margin: 20px auto;
    padding: 20px;
    border: 1px solid #ddd;
    border-radius: 12px;
    background: white;
    box-shadow: 0 4px 8px rgba(0,0,0,0.1);
}

.card h3 {
    margin-top: 0;
    margin-bottom: 12px;
}

.card p {
    margin: 0;
    line-height: 1.4;
}

Dzięki border-box karta ma zawsze 300px szerokości, niezależnie od tego, ile wynosi padding i border.

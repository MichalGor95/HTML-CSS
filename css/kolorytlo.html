Rozdział CSS: Kolory i tło

Kolory i tła nadają stronie charakter. W CSS możesz sterować kolorem tekstu, tłem elementów, obrazkami w tle i ich pozycjonowaniem.

1. Kolor tekstu - color

Właściwość color ustawia kolor tekstu oraz kolor obramowania (jeśli nie określono osobno). 

p {
    color: navy;
}

.warning {
    color: #ff0000;  /* czerwony w HEX */
}

.success {
    color: rgb(0, 128, 0);  /* zielony RGB */
}

color dziedziczy się - dzieci przejmują kolor rodzica, chyba że go nadpiszą.

2. Kolor tła - background-color

Ustawia kolor tła elementu. Może przyjmować wszystkie formaty kolorów oraz transparent (domyślnie). 

body {
    background-color: #f5f5f5;
}

.highlight {
    background-color: yellow;
}

.dark {
    background-color: rgba(0, 0, 0, 0.7);  /* półprzezroczysty czarny */
}
WartośćPrzykładEfekt
nazwa kolorured, blue, lightgreen135 nazw kolorów
HEX#ff6600, #f60szesnastkowo (3 lub 6 znaków)
RGB / RGBArgb(255,102,0), rgba(0,0,0,0.5)0-255, alpha = przezroczystość
HSL / HSLAhsl(24,100%,50%), hsla(0,100%,50%,0.3)odcień, nasycenie, jasność

3. Obrazek w tle - background-image

Wstawia obrazek jako tło elementu. Domyślnie obrazek powtarza się w poziomie i pionie. 

.header {
    background-image: url('obrazy/tlo.jpg');
}

.hero {
    background-image: linear-gradient(to right, #ff8c00, #ff0080);
    /* gradient też jest obrazkiem! */
}

Można podać wiele obrazków oddzielonych przecinkami - nakładają się (pierwszy na wierzchu).

4. Powtarzanie tła - background-repeat

Steruje, czy i jak obrazek tła ma się powtarzać.

WartośćOpis
repeatpowtarzanie w poziomie i pionie (domyślnie)
repeat-xpowtarzanie tylko w poziomie
repeat-ypowtarzanie tylko w pionie
no-repeatbez powtarzania, obrazek pojawia się raz
spacepowtarzanie z równymi odstępami
roundskalowanie tak, aby całkowicie wypełnić
 
.tlo1 { background-repeat: repeat-x; }
.tlo2 { background-repeat: no-repeat; }

5. Rozmiar tła - background-size

Określa rozmiar obrazka tła.

WartośćDziałanie
autooryginalny rozmiar (domyślnie)
coverskaluje obraz tak, aby pokrył cały element (może uciąć)
containskaluje obraz tak, aby cały zmieścił się w elemencie
100px 200pxkonkretna szerokość i wysokość
50% 50%procenty względem elementu
 
.hero {
    background-image: url('panorama.jpg');
    background-size: cover;
    background-repeat: no-repeat;
}

6. Pozycjonowanie tła - background-position

Ustawia początkową pozycję obrazka tła (gdy nie jest powtarzany lub jest większy od elementu).

WartośćPrzykładZnaczenie
słowa kluczoweleft top, center center, right bottompozycje narożne / środek
jednostki20px 30pxodsunięcie od lewego górnego rogu
procenty50% 50%środek elementu
 
.ikona {
    background-image: url('strzalka.png');
    background-repeat: no-repeat;
    background-position: right center;  /* prawa strona, pionowo na środku */
}

7. Formaty kolorów - RGB, HEX, HSL

W CSS kolory można zapisywać na kilka sposobów.

HEX (szesnastkowo)

#RRGGBB lub #RGB (skrócony).

#ffffff  /* biały */
#000     /* czarny (skrót od #000000) */
#f60     /* pomarańczowy (skrót od #ff6600) */

RGB / RGBA

Funkcje rgb(red, green, blue) - każda składowa 0-255. rgba z kanałem alpha (przezroczystość) 0-1.

rgb(255, 0, 0)     /* czerwony */
rgba(0, 128, 0, 0.5) /* zielony przezroczysty */

HSL / HSLA

hsl(hue, saturation, lightness) - hue 0-360 (kąt), saturation 0-100%, lightness 0-100%.

hsl(0, 100%, 50%)    /* czerwony */
hsl(120, 50%, 75%)   /* jasnozielony */
hsla(240, 100%, 50%, 0.3) /* niebieski przezroczysty */
FormatPrzykładKiedy używać?
HEX#2f7a67popularny, łatwy do kopiowania z grafiki

8. Skrócona właściwość background

Pozwala ustawić wszystkie cechy tła w jednej linii. Kolejność nie jest ścisła, ale zalecana: color image repeat position / size attachment. 

body {
    background: #f0f0f0 url('tlo.png') no-repeat center center / cover fixed;
}

/* to samo co: */
body {
    background-color: #f0f0f0;
    background-image: url('tlo.png');
    background-repeat: no-repeat;
    background-position: center center;
    background-size: cover;
    background-attachment: fixed;
}

Skrócona składnia jest częsta na egzaminie INF03 - warto ją zapamiętać.

9. Przykład - karta z gradientem i obrazkiem

.card {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%),
                url('pattern.png');
    background-blend-mode: overlay;
    color: white;
    padding: 2rem;
    border-radius: 1rem;
}

Łączenie kolorów, gradientów i obrazków daje nieskończone możliwości. W kolejnych rozdziałach poznasz background-blend-mode (tryby mieszania).

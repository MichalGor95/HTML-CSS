Rozdział 16: Osadzanie treści (iframe)

Element <iframe> (inline frame) pozwala osadzać zewnętrzne strony, mapy, filmy z YouTube, dokumenty PDF i inne zasoby. Poznaj składnię, atrybuty, zasady bezpieczeństwa oraz dobre praktyki.

1. <iframe> - podstawowe użycie

<iframe> tworzy osadzoną ramkę, która wyświetla inną stronę internetową lub zasób. Podstawowe atrybuty to src (adres), width i height (rozmiary).

<iframe src="https://example.com" width="600" height="400" title="Przykładowa strona"></iframe>

Przykład pustego iframe (about:blank). W praktyce podajesz konkretny URL.

Atrybut title jest bardzo ważny dla dostępności - czytniki ekranu używają go do opisania ramki.

2. Osadzanie mapy Google

Mapy Google udostępniają łatwy w użyciu kod do osadzenia. Wystarczy wybrać lokalizację, kliknąć "Udostępnij" → "Osadź mapę" i skopiować kod <iframe>.

<iframe 
    src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d2561.2!2d19.937!3d50.061!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x47165b0e4d6b6d3b%3A0x5e8e1c8c1b1b1b1b!2sRynek%20G%C5%82%C3%B3wny!5e0!3m2!1spl!2spl!4v1234567890" 
    width="600" 
    height="450" 
    style="border:0;" 
    allowfullscreen="" 
    loading="lazy" 
    title="Mapa Google - Rynek Główny w Krakowie">
</iframe>

Przykład osadzonej mapy (uproszczony adres - w rzeczywistości użyj kodu z Google Maps).

  • Google Maps automatycznie generuje atrybut allowfullscreen i loading="lazy".
  • Zalecane jest dodanie style="border:0;", aby usunąć domyślną ramkę.
  • Możesz dostosować rozmiary (width, height) do swoich potrzeb.

3. Osadzanie filmu z YouTube

YouTube udostępnia łatwy kod do osadzania wideo. Kliknij "Udostępnij" → "Osadź" i skopiuj <iframe>. Pamiętaj o parametrach w URL (np. ?autoplay=0&controls=1).

<iframe 
    width="560" 
    height="315" 
    src="https://www.youtube.com/embed/dQw4w9WgXcQ" 
    title="YouTube video player" 
    frameborder="0" 
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" 
    referrerpolicy="strict-origin-when-cross-origin" 
    allowfullscreen>
</iframe>

Przykład osadzonego filmu z YouTube (w rzeczywistej stronie użyj własnego filmu).

allowfullscreen - umożliwia przejście na pełny ekran.
allow - lista uprawnień (autoodtwarzanie, kamera, mikrofon).
referrerpolicy - kontrola przesyłania referera.
Możesz modyfikować parametry w URL: ?autoplay=1 (autoodtwarzanie), ?controls=0 (ukrycie kontrolek), ?loop=1 (zapętlenie). Pamiętaj, że autoplay często wymaga muted w nowych przeglądarkach.

4. Inne zastosowania <iframe>

  • Osadzanie dokumentów PDF - <iframe src="dokument.pdf"></iframe>
  • Formularze zewnętrzne - np. Google Forms, Typeform.
  • Osadzanie treści social media - posty z Facebooka, Twittera (X), Instagrama.
  • Prezentacje - Slideshare, Prezi, Canva.
<iframe src="prezentacja.pdf" width="100%" height="500" title="Dokument PDF"></iframe>

5. Atrybuty iframe - szczegółowe omówienie

AtrybutOpisPrzykład
src Adres URL osadzanego dokumentu. Scoś * (wymagany) - może być http, https, about:blank. src="https://example.com"
srcdoc (HTML5) Osadza bezpośrednio kod HTML zamiast ładować z URL. Ma pierwszeństwo przed src. srcdoc="<p>Treść</p>"
width / height Rozmiary ramki (w pikselach lub %). width="100%" height="400"
name Nazwa ramki - przydatna dla atrybutu target w linkach. name="menu"
allowfullscreen Pozwala na przejście do trybu pełnoekranowego (wideo, mapy). allowfullscreen (boolean)
sandbox (bezpieczeństwo) Ogranicza możliwości osadzanej treści (np. brak skryptów, brak przesyłania formularzy). sandbox="allow-same-origin allow-scripts"
loading Leniwie ładuje ramkę ("lazy") - poprawia wydajność. loading="lazy"
title Opis ramki dla czytników ekranu (dostępność). title="Mapa dojazdu"
Atrybut sandbox zwiększa bezpieczeństwo, ale może zablokować działanie osadzanej strony (np. JavaScript, formularze). Używaj go świadomie.

6. Bezpieczeństwo i atrybut sandbox

sandbox pozwala na odseparowanie osadzonej treści. Można stopniowo zezwalać na określone funkcje.

<iframe src="https://nieznanastrona.pl" sandbox></iframe>
<!-- całkowicie odizolowane - brak skryptów, formularzy, wyskakujących okien -->

<iframe src="https://zaufana.strona.pl" sandbox="allow-same-origin allow-scripts allow-forms"></iframe>
<!-- pozwala na skrypty, formularze, ale wciąż ogranicza inne funkcje -->
Wartości sandbox oddzielamy spacjami: allow-same-origin allow-scripts allow-popups. Użycie samego sandbox bez wartości ustawia maksymalne ograniczenia.

7. Dostępność i dobre praktyki

Dobre praktyki

  • Zawsze dodawaj atrybut title z opisem ramki.
  • Ustaw odpowiednie rozmiary (width i height) lub użyj CSS dla responsywności.
  • Dodaj loading="lazy" dla iframe poza pierwszym ekranem - przyspiesza ładowanie strony.
  • Używaj sandbox dla nieznanych źródeł.
  • Zapewnij tekst zastępczy między tagami <iframe> dla przeglądarek go nieobsługujących.

Błędy

  • Brak atrybutu title - problem z dostępnością.
  • Brak responsywności (iframe poza skalowaniem na telefonach).
  • Osadzanie nieznanych stron bez sandbox - ryzyko XSS.
  • Używanie frameborder (przestarzałe) zamiast CSS (style="border:0;").

8. Responsywne iframe - CSS

Aby iframe skalował się na urządzeniach mobilnych, często stosuje się technikę "intrinsic ratio".

<style>
    .iframe-container {
        position: relative;
        width: 100%;
        padding-bottom: 56.25%; /* proporcje 16:9 */
        height: 0;
    }
    .iframe-container iframe {
        position: absolute;
        top: 0;
        left: 0;
        width: 100%;
        height: 100%;
    }
</style>

<div class="iframe-container">
    <iframe src="https://www.youtube.com/embed/..." title="Film"></iframe>
</div>
Dla map Google i YouTube warto stosować responsywne kontenery, aby uniknąć przewijania poziomego na małych ekranach.

9. Przykład strony z różnymi iframe

<h3>Nasza lokalizacja</h3>
<iframe src="https://www.google.com/maps/embed?pb=..." width="100%" height="350" style="border:0;" allowfullscreen loading="lazy" title="Mapa biura"></iframe>

<h3>Film promocyjny</h3>
<iframe width="100%" height="400" src="https://www.youtube.com/embed/abc123" title="Promocja" allowfullscreen></iframe>

<h3>Dokument PDF</h3>
<iframe src="regulamin.pdf" width="100%" height="600" title="Regulamin">
    Twoja przeglądarka nie obsługuje iframe. <a href="regulamin.pdf">Pobierz PDF</a>.
</iframe>

10. Co musisz zapamiętać na egzamin INF03

<iframe> - osadzanie zewnętrznych dokumentów.
src - adres osadzanej treści.
width / height - rozmiary ramki.
allowfullscreen - pełny ekran (dla wideo/map).
loading="lazy" - leniwe ładowanie.
sandbox - bezpieczeństwo (ograniczenia).
title - dostępność.
Egzaminatorzy mogą poprosić o osadzenie mapy Google lub filmu z YouTube na stronie. Pamiętaj o poprawnym skopiowaniu kodu z serwisu i ewentualnej modyfikacji rozmiarów. 
<!-- Wzorcowy iframe YouTube -->
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" 
    title="Tytuł filmu" frameborder="0" allow="accelerometer; autoplay; clipboard-write; 
    encrypted-media; gyroscope; picture-in-picture" allowfullscreen>
</iframe>

<!-- Wzorcowa mapa Google -->
<iframe src="https://www.google.com/maps/embed?pb=..." 
    width="600" height="450" style="border:0;" allowfullscreen loading="lazy" 
    title="Mapa dojazdu">
</iframe>

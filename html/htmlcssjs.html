Rozdział 18: HTML + CSS + JavaScript

Współczesna strona internetowa łączy trzy technologie: HTML (struktura), CSS (wygląd) i JavaScript (zachowanie). Poznaj jak podłączać arkusze stylów i skrypty, podstawy CSS oraz proste przykłady JS.

1. Trzy filary nowoczesnej strony

TechnologiaRolaPrzykład
HTML (HyperText Markup Language) Struktura i treść - nagłówki, akapity, obrazy, linki. Boot * (co robiliśmy przez 17 rozdziałów) - odpowiada za to, co jest na stronie./ <h1>Tytuł</h1>, <p>Tekst</p>
CSS (Cascading Style Sheets) Wygląd i układ - kolory, czcionki, rozmieszczenie, responsywność. Rozdziela treść od prezentacji. color: red; font-size: 20px; margin: 10px;
JavaScript (JS) Interaktywność - reagowanie na kliknięcia, walidacja formularzy, dynamiczne zmiany treści, animacje. Boot * (to już programowanie) - wykonuje akcje po stronie klienta./ alert('Witaj!');, zmiana stylu po kliknięciu
Zasada separacji: HTML = treść, CSS = wygląd, JS = zachowanie. Dzięki temu kod jest czytelniejszy i łatwiejszy w utrzymaniu.

2. Podpinanie CSS - <link> i <style>

CSS można dodać na trzy sposoby. Najczęściej stosuje się zewnętrzny arkusz stylów (<link>) lub wewnętrzny (<style>).

Metoda 1: Zewnętrzny arkusz stylów (zalecana)

<!-- W sekcji <head> -->
<link rel="stylesheet" href="../style.css">
  • Plik style.css zawiera wszystkie reguły CSS.
  • Można go użyć na wielu stronach - spójność całej witryny.
  • Łatwiejsze utrzymanie i szybsze ładowanie (cache).

Metoda 2: Wewnętrzny arkusz stylów (<style>)

<style>
    body {
        font-family: Arial;
        background-color: #f3f1eb;
    }
    h1 {
        color: #2f7a67;
    }
</style>
  • Umieszczony w <head> (rzadziej w <body>).
  • Dotyczy tylko jednej strony - brak ponownego użycia.

Metoda 3: Style inline (atrybut style) - unikaj!

<p style="color: red; font-size: 20px;">Tekst</p>
Style inline mieszają wygląd ze strukturą - utrudniają utrzymanie. Stosuj tylko w wyjątkowych sytuacjach.

3. Podstawy CSS - składnia, selektory, właściwości

CSS składa się z selektorów (co stylizujemy) i deklaracji (jak stylizujemy).

selektor {
    właściwość: wartość;
    właściwość: wartość;
}

/* Przykład */
h1 {
    color: #2f7a67;
    font-size: 32px;
    text-align: center;
}

Najważniejsze selektory

SelektorPrzykładOpis
Element (tag)p { }Wszystkie akapity
Klasa (class) .nazwa { } Wszystkie elementy z class="nazwa"
Identyfikator (id) #unikalny { } Jeden element z id="unikalny" (unikalny na stronie)
Zagnieżdżony nav ul li a { } Linki wewnątrz listy w nawigacji

Popularne właściwości CSS

color - kolor tekstu.
color: #2f7a67;
background-color - kolor tła.
background: #f4f1ea;
font-size - rozmiar czcionki.
font-size: 18px;
margin / padding - odstępy zewn./wewn.
margin: 10px; padding: 20px;
border - ramka.
border: 1px solid #ccc;
display - sposób wyświetlania (block, inline, flex).
display: flex;
Przykład stylowanego bloku: tło #eef3f0, zielona ramka, zaokrąglone rogi, efekt najechania (hover).

4. Podpinanie JavaScript - <script>

JavaScript można dodać podobnie jak CSS: zewnętrzny plik lub wewnętrzny skrypt. Zwykle umieszcza się go przed końcem <body>, aby nie blokował ładowania strony.

Zewnętrzny plik JS (zalecany)

<script src="skrypt.js"></script>

Wewnętrzny skrypt (w HTML)

<script>
    alert("Witaj na stronie!");
    console.log("Komunikat w konsoli");
</script>
Atrybut defer lub umieszczenie skryptu na końcu <body> powoduje, że JS wykonuje się po załadowaniu całej treści.

5. Podstawy JavaScript - zdarzenia i proste akcje

JavaScript pozwala reagować na działania użytkownika (kliknięcie, najechanie, wypełnienie formularza). Oto kilka podstawowych przykładów.

Przykład 1: alert() - okno dialogowe

<button onclick="alert('Kliknięto przycisk!')">Kliknij</button>

Przykład 2: Zmiana treści elementu

<p id="demo">Tekst przed zmianą</p>
<button onclick="document.getElementById('demo').innerHTML = 'Nowy tekst!'">Zmień</button>

Tekst przed zmianą

Przykład 3: Zmiana stylu CSS

<p id="styl">Kolor tego tekstu się zmieni.</p>
<button onclick="document.getElementById('styl').style.color = 'red';">Na czerwony</button>
<button onclick="document.getElementById('styl').style.color = '#222';">Przywróć</button>

Kolor tego tekstu się zmieni.

JavaScript to pełnoprawny język programowania (zmienne, funkcje, pętle). Na egzaminie INF03 wystarczy znajomość prostych zdarzeń i modyfikacji DOM.

6. Przykład strony łączącej HTML+CSS+JS

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Moja strona</title>
    <link rel="stylesheet" href="../style.css">
    <style>
        .highlight { background-color: yellow; }
    </style>
</head>
<body>
    <h1>Witaj na stronie</h1>
    <button onclick="zmienTekst()">Kliknij</button>
    <p id="komunikat">Wiadomość</p>

    <script>
        function zmienTekst() {
            document.getElementById('komunikat').innerHTML = 'Kliknięto!';
            document.getElementById('komunikat').classList.add('highlight');
        }
    </script>
</body>
</html>

7. Kolejność ładowania - gdzie umieszczać <script>?

  • W <head> - może blokować renderowanie, jeśli skrypt jest duży. Używaj defer.
  • Przed </body> - zalecane, ponieważ HTML ładuje się najpierw, a skrypt wykonuje się na końcu.
  • Atrybut defer - skrypt wykonuje się po załadowaniu dokumentu (działa tylko dla zewnętrznych).
  • Atrybut async - skrypt ładuje się asynchronicznie, wykonuje zaraz po pobraniu.
<!-- Zewnętrzny skrypt z defer -->
<script src="skrypt.js" defer></script>

<!-- Skrypt przed końcem body -->
<body>
    ...
    <script src="skrypt.js"></script>
</body>

8. Dobre praktyki łączenia technologii

Dobre praktyki

  • CSS i JS w osobnych plikach (link, src).
  • Unikaj stylów i zdarzeń inline (style, onclick w HTML).
  • Używaj klas CSS zamiast zmiany stylów bezpośrednio w JS.
  • Umieszczaj skrypty przed </body>.
  • Zapewnij działanie strony bez JS (progresywne ulepszanie).

Błędy

  • Mieszanie stylów inline i zewnętrznych.
  • Ładowanie skryptów w <head> bez defer - blokowanie wyświetlania.
  • Brak średników lub zamykających nawiasów w JS.
  • Nieprawidłowa ścieżka do pliku CSS/JS (błąd 404).

Rozdział 9: Kontenery i grupowanie

<div> i <span> to uniwersalne pojemniki do grupowania elementów. Służą głównie do zastosowania stylów CSS oraz manipulacji JavaScript. Poznaj różnice między blokowym a liniowym kontenerem oraz dobre praktyki.

1. <div> - blokowy kontener

<div> (division) to element blokowy. Zajmuje całą dostępną szerokość, rozpoczyna nową linię i może zawierać dowolne inne elementy (blokowe i liniowe). Najczęściej używany do tworzenia sekcji, layoutu, kontenerów dla CSS.

<div class="kontener">
    <h2>Nagłówek w divie</h2>
    <p>Akapit tekstu wewnątrz tego samego kontenera.</p>
</div>

Nagłówek w divie

Akapit tekstu wewnątrz tego samego kontenera.

  • Blokowość - zawsze zaczyna od nowej linii, rozciąga się na całą szerokość rodzica.
  • Brak znaczenia semantycznego - używaj go tylko gdy nie ma odpowiedniego znacznika HTML5 (np. <section>, <article>).
  • Atrybuty - najczęściej class, id, style, data-*.
W HTML5 zamiast <div> warto stosować semantyczne znaczniki (<header>, <main>, <section>, <article>, <aside>, <footer>), ale <div> wciąż jest niezbędny do grupowania elementów bez znaczenia.

2. <span> - liniowy kontener

<span> to element liniowy (inline). Nie łamie linii, zajmuje tylko tyle miejsca, ile potrzebuje jego zawartość. Idealny do wyróżniania fragmentów tekstu wewnątrz akapitu.

<p>To jest <span style="color: #2f7a67; font-weight: bold;">ważny fragment</span> w zdaniu.</p>

To jest ważny fragment w zdaniu.

Liniowy - nie tworzy nowej linii, może występować obok innych elementów liniowych.
Zastosowanie - podświetlenie słów, ikony w tekście, dynamiczna zmiana treści (JS).
Nie umieszczaj elementów blokowych (np. <div>, <p>) wewnątrz <span> - to niepoprawne składniowo.

3. Porównanie div vs span

Cecha<div><span>
TypBlokowy (block)Liniowy (inline)
Nowa liniaTak (zaczyna od nowej linii)Nie (pozostaje w linii)
SzerokośćCała dostępna szerokość rodzicaZgodna z zawartością
Może zawieraćElementy blokowe i linioweTylko elementy liniowe i tekst

Za pomocą CSS możesz zmienić zachowanie: display: inline dla div lub display: block dla span, ale lepiej od razu używać odpowiedniego znacznika.

4. Grupowanie elementów - praktyczne zastosowania

Kontenery <div> i <span> są podstawą nowoczesnych technik CSS (Flexbox, Grid) oraz manipulacji DOM.

Przykład 1: Stylowanie całej sekcji

<div class="card">
    <h3>Karta produktu</h3>
    <p>Cena: 199 zł</p>
    <button>Kup</button>
</div>

Karta produktu

Cena: 199 zł

Przykład 2: Wyróżnienie słowa w tekście

<p>Kliknij <span class="highlight">tutaj</span>, aby zapisać się na newsletter.</p>

Kliknij tutaj, aby zapisać się na newsletter.

Przykład 3: Layout strony z divami (klasyczny układ)

<div class="header">Nagłówek</div>
<div class="container">
    <div class="sidebar">Menu boczne</div>
    <div class="content">Treść główna</div>
</div>
<div class="footer">Stopka</div>
Dziś do layoutu zaleca się używanie semantycznych znaczników HTML5 (<header>, <nav>, <main>, <footer>) oraz CSS Grid/Flexbox, ale <div> wciąż jest używany wewnątrz tych sekcji.

5. Atrybuty class i id - klucz do grupowania i stylowania

Kontenery najczęściej otrzymują atrybuty class (do wielokrotnego użycia) lub id (unikalny identyfikator). To pozwala na podpięcie CSS i JavaScript.

<div class="produkt" id="produkt-1">
    <span class="cena">99 zł</span>
</div>
class - może być przypisana do wielu elementów. W CSS: .nazwa.
id - unikalny w obrębie strony. W CSS: #nazwa. Wyższa specyficzność.
style - stylowanie inline (unikać, jeśli to możliwe).
data-* - atrybuty do przechowywania danych dla JavaScript.

6. Kiedy używać div, a kiedy semantycznych znaczników?

Używaj <div>, gdy:

  • Potrzebujesz kontenera wyłącznie do stylizacji (CSS).
  • Grupujesz elementy, które nie mają logicznego znaczenia (np. wiersz w gridzie).
  • Brak odpowiedniego semantycznego znacznika HTML5.

Używaj znaczników semantycznych, gdy:

  • Jest to nagłówek (<header>), nawigacja (<nav>), sekcja (<section>), artykuł (<article>), stopka (<footer>).
  • Chcesz poprawić SEO i dostępność.
Nadmiar <div> to tzw. "divitis" - staraj się używać minimalnej liczby kontenerów, tylko gdy są naprawdę potrzebne.

7. Przykład złożony - karta produktu z div i span

<div class="product-card">
    <h3>Smartfon XYZ</h3>
    <div class="price">
        <span class="old-price">1999 zł</span>
        <span class="new-price">1499 zł</span>
    </div>
    <p>Najlepszy telefon na rynku! <span class="badge">Promocja</span></p>
    <button>Kup teraz</button>
</div>

Smartfon XYZ

1999 zł 1499 zł

Najlepszy telefon na rynku! Promocja

8. Zagnieżdżanie div i span

Kontenery można dowolnie zagnieżdżać, ale pamiętaj o poprawnym domykaniu i zachowaniu typu (blokowy w liniowym jest niedozwolony).

<div class="wrapper">
    <div class="inner">
        <p>Tekst z <span class="accent">akcentem</span>.</p>
    </div>
</div>
Nie możesz umieścić <div> wewnątrz <span> - to narusza składnię HTML (element blokowy wewnątrz liniowego).

9. Praktyka - grupowanie w formularzach

<div class="form-group">
    <label>Imię: </label>
    <input type="text" name="imie">
</div>
<div class="form-group">
    <label>E-mail: </label>
    <input type="email" name="email">
</div>

10. Co musisz zapamiętać na egzamin INF03

<div> - blokowy kontener (zajmuje całą szerokość, nowa linia).
<span> - liniowy kontener (tylko tyle miejsca ile treść).
Grupowanie - umożliwia stylowanie CSS i manipulację JS.
class / id - identyfikatory do podpinania stylów i skryptów.
Semantyka - używaj div tylko gdy brak odpowiedniego znacznika HTML5.
Egzaminatorzy często sprawdzają, czy rozumiesz różnicę między elementami blokowymi a liniowymi. Pamiętaj: <div> jest blokowy, <span> liniowy.

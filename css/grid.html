Rozdział CSS: CSS Grid

CSS Grid Layout to dwuwymiarowy system układu strony, który pozwala tworzyć złożone, responsywne struktury zarówno w poziomie, jak i pionie. W przeciwieństwie do Flexboxa (jednokierunkowego), Grid operuje na wierszach i kolumnach jednocześnie. Jest często używany do budowy całego layoutu strony, galerii i dashboardów.

1. Czym jest CSS Grid?

Grid pozwala zdefiniować siatkę - zbiór kolumn i wierszy - a następnie umieszczać w niej elementy. Można precyzyjnie kontrolować rozmiary, odstępy i pozycje.

  • display: grid - tworzy kontener siatki
  • grid-template-columns - definiuje kolumny
  • grid-template-rows - definiuje wiersze
  • grid-area - nazwany obszar lub pozycja elementu
  • repeat() - powtarzanie wzorca
  • fr - jednostka elastyczna (fraction)
  • gap - odstępy między komórkami

2. display: grid - tworzenie kontenera siatki

Ustawienie display: grid na rodzicu przekształca go w kontener siatki. Bezpośrednie dzieci stają się elementami siatki. 

.kontener {
    display: grid;
}

3. grid-template-columns - definiowanie kolumn

Określa liczbę i szerokość kolumn. Każda wartość to szerokość jednej kolumny. 

/* trzy kolumny o stałej szerokości */
.kontener {
    display: grid;
    grid-template-columns: 100px 200px 100px;
}

/* kolumny elastyczne z jednostką fr */
.kontener {
    grid-template-columns: 1fr 2fr 1fr;  /* proporcje 1:2:1 */
}

4. grid-template-rows - definiowanie wierszy

Określa wysokość wierszy. Domyślnie wiersze mają wysokość automatyczną (dopasowaną do treści). 

.kontener {
    display: grid;
    grid-template-columns: 1fr 1fr;
    grid-template-rows: 100px 200px;  /* dwa wiersze: pierwszy 100px, drugi 200px */
}

5. repeat() - uproszczenie definicji

Funkcja repeat() pozwala powtórzyć wzorzec kolumn lub wierszy bez ręcznego wypisywania. 

/* 4 kolumny po 100px */
grid-template-columns: repeat(4, 100px);

/* 3 kolumny: 1fr, 2fr, 1fr */
grid-template-columns: repeat(3, 1fr 2fr 1fr); /* uwaga: 3 × (1fr 2fr 1fr) = 9 kolumn */

/* często używane: responsywna siatka */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
repeat(4, 80px) - 4 kolumny po 80px

6. Jednostka fr - elastyczne proporcje

fr (fraction) oznacza część dostępnej przestrzeni w kontenerze. Jest kluczowa w Grid - pozwala tworzyć proporcjonalne kolumny i wiersze. 

/* 3 kolumny: druga zajmuje 2 razy więcej niż pierwsza i trzecia */
grid-template-columns: 1fr 2fr 1fr;

/* 2 kolumny: pierwsza 250px, druga reszta */
grid-template-columns: 250px 1fr;

/* mieszane jednostki */
grid-template-columns: 100px 2fr 1fr;

7. gap - odstępy między komórkami

Właściwość gap (dawniej grid-gap) ustawia odstępy między wierszami i kolumnami. 

.kontener {
    display: grid;
    gap: 20px;           /* równe odstępy w pionie i poziomie */
    gap: 10px 20px;      /* wiersze 10px, kolumny 20px */
    row-gap: 15px;       /* tylko odstęp między wierszami */
    column-gap: 25px;    /* tylko między kolumnami */
}

8. grid-area - pozycjonowanie i nazwane obszary

grid-area może być używana na dwa sposoby:

  • jako skrót dla grid-row-start / grid-column-start / grid-row-end / grid-column-end
  • jako nazwa obszaru zdefiniowanego przez grid-template-areas
/* Metoda 1: pozycja liczbowa */
.item {
    grid-area: 2 / 1 / 3 / 3;  /* start wiersz 2, kolumna 1, koniec wiersz 3, kolumna 3 */
}

/* Metoda 2: nazwane obszary (najpopularniejsza dla layoutu) */
.kontener {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
    grid-template-columns: 200px 1fr 1fr;
    grid-template-rows: auto 1fr auto;
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

10. Przykład - pełny layout strony z Grid

<style>
    .page {
        display: grid;
        grid-template-areas:
            "nav nav nav"
            "sidebar main main"
            "footer footer footer";
        grid-template-columns: 250px 1fr 1fr;
        grid-template-rows: auto 1fr auto;
        min-height: 100vh;
        gap: 16px;
    }
    .nav {
        grid-area: nav;
        background: #333;
        color: white;
        padding: 1rem;
    }
    .sidebar {
        grid-area: sidebar;
        background: #f4f4f4;
        padding: 1rem;
    }
    .main {
        grid-area: main;
        background: white;
        padding: 1rem;
    }
    .footer {
        grid-area: footer;
        background: #333;
        color: white;
        padding: 1rem;
        text-align: center;
    }
    @media (max-width: 768px) {
        .page {
            grid-template-areas:
                "nav"
                "sidebar"
                "main"
                "footer";
            grid-template-columns: 1fr;
        }
    }
</style>

12. Ćwiczenia INF03

Pytanie 1: Co oznacza jednostka fr w CSS Grid?

Odpowiedź: fr to jednostka elastyczna oznaczająca część dostępnej przestrzeni w kontenerze (fraction).

Pytanie 2: Jak zdefiniować 3 kolumny, gdzie pierwsza ma 100px, a pozostałe dzielą resztę po równo?

grid-template-columns: 100px 1fr 1fr;

Pytanie 3: Co robi repeat(4, minmax(100px, 1fr))?

Odpowiedź: Tworzy 4 kolumny, każda o minimalnej szerokości 100px i maksymalnie 1fr (elastycznie).

Pytanie 4: Jak zrobić prosty layout: nagłówek, menu boczne, treść, stopka?

.grid {
    display: grid;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
    grid-template-columns: 200px 1fr;
}

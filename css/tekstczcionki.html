Rozdział CSS: Tekst i czcionki

Wygląd tekstu wpływa na czytelność i estetykę strony. CSS daje pełną kontrolę nad krojem, rozmiarem, grubością, odstępami i wyrównaniem tekstu.

1. Krój czcionki - font-family

Określa, jakiej czcionki ma użyć przeglądarka. Podaje się listę "fallback" - jeśli pierwszej nie ma, używana jest następna. 

body {
    font-family: Arial, Helvetica, sans-serif;
}

h1 {
    font-family: 'Times New Roman', Times, serif;
}

.specjalny {
    font-family: 'Courier New', monospace;
}
Rodzaj ogólnyPrzykłady czcionekZastosowanie
sans-serifArial, Helvetica, Verdana, Robotoczytelna na ekranie, bez szeryfów
serifTimes New Roman, Georgia, Garamondtradycyjna, do druku
monospaceCourier New, Consolas, Monacokody źródłowe, terminale
cursiveComic Sans MS, cursiveodręczne, dekoracyjne
fantasyImpact, Papyrusefektowne, nagłówki

Zawsze kończ listę rodzajem ogólnym (np. sans-serif).

2. Rozmiar czcionki - font-size

Ustawia rozmiar tekstu. Można używać różnych jednostek. 

p {
    font-size: 16px;     /* piksele - sztywny rozmiar */
}

h1 {
    font-size: 2.5rem;   /* względem root'a (zwykle 16px = 2.5rem = 40px) */
}

small {
    font-size: 0.8em;    /* względem rodzica */
}
JednostkaOpis
pxpiksele - absolutna, najczęstsza
emwzględna - względem rozmiaru czcionki rodzica
remwzględna - względem rozmiaru czcionki elementu <html> (domyślnie 16px)
%procenty - względem rodzica
vw, vhwzględem szerokości/wysokości okna

Dobra praktyka: rem dla ogólnego rozmiaru, em dla elementów zależnych od kontekstu.

3. Grubość czcionki - font-weight

Określa pogrubienie tekstu. 

strong {
    font-weight: bold;      /* 700 */
}

.normal {
    font-weight: normal;    /* 400 */
}

.light {
    font-weight: 300;       /* cienka */
}

.black {
    font-weight: 900;       /* bardzo gruba */
}
Wartość słownaWartość numerycznaEfekt
normal400normalna
bold700pogrubiona
lighter--
bolder--
100,200,...,900wielokrotności 100od bardzo cienkiej (100) do bardzo grubej (900)

️ Nie wszystkie czcionki obsługują wszystkie grubości - trzeba sprawdzić.

4. Styl czcionki - font-style

Najczęściej używany do kursywy. 

em, i {
    font-style: italic;   /* kursywa */
}

.uwaga {
    font-style: oblique;  /* pochylona (sztuczna) */
}

.zwykly {
    font-style: normal;
}

Różnica między italic a oblique: italic to specjalna kursywa projektanta, oblique to zwykła czcionka sztucznie pochylona.

5. Wyrównanie tekstu - text-align

Wyrównuje tekst w bloku (np. akapicie, divie). 

.lewy {
    text-align: left;      /* domyślnie */
}

.prawy {
    text-align: right;
}

.srodek {
    text-align: center;
}

.justowany {
    text-align: justify;   /* wyjustowanie - równe marginesy */
}

text-align: justify jest często używane w artykułach, ale może tworzyć brzydkie przerwy między wyrazami.

6. Dekoracja tekstu - text-decoration

Dodaje linie pod tekstem, nad nim lub przez niego. 

a {
    text-decoration: none;       /* usuwa podkreślenie z linków */
}

.przekreslony {
    text-decoration: line-through;  /* przekreślenie */
}

.nadkreslony {
    text-decoration: overline;
}

.podkreslony {
    text-decoration: underline;
}

.kombinacja {
    text-decoration: underline wavy red;  /* CSS3 - kolor i styl */
}
WłaściwośćPrzykładOpis
text-decoration-lineunderline, overline, line-throughrodzaj linii
text-decoration-colorred, #00fkolor linii
text-decoration-stylesolid, dotted, dashed, wavystyl linii

7. Wysokość linii - line-height

Odstęp między wierszami tekstu. Wpływa na czytelność. 

p {
    line-height: 1.5;      /* 1.5 * rozmiar czcionki - najczęściej */
}

.ciasto {
    line-height: 2;        /* podwójny odstęp */
}

.scisly {
    line-height: 1.2;
}

Zalecane wartości: 1.4 - 1.6 dla tekstu ciągłego. Wartość bez jednostki (np. 1.5) jest lepsza od px, bo skaluje się z czcionką.

Można też używać px lub em, ale wtedy nie skaluje się proporcjonalnie.

8. Odstęp między literami - letter-spacing

Zwiększa lub zmniejsza odstępy między znakami. 

.rozstrzelony {
    letter-spacing: 2px;
}

.scisly {
    letter-spacing: -0.5px;  /* ujemna wartość zbliża litery */
}

.naglowek {
    letter-spacing: 4px;
    text-transform: uppercase;
}

Przydatne w nagłówkach, logo, akcentach. Długi tekst nie powinien mieć dużego letter-spacing, bo traci czytelność.

9. Skrócona właściwość font

Łączy wiele właściwości czcionki w jednej linii. Kolejność (zalecana): font-style font-weight font-size/line-height font-family. 

body {
    font: italic normal 16px/1.5 Arial, sans-serif;
}

/* to samo co: */
body {
    font-style: italic;
    font-weight: normal;
    font-size: 16px;
    line-height: 1.5;
    font-family: Arial, sans-serif;
}

️ Uwaga: font-family i font-size są wymagane. Jeśli pominiesz line-height, nie zostanie ono nadpisane.

10. Przykład - stylizacja artykułu

article {
    font-family: 'Georgia', serif;
    font-size: 18px;
    line-height: 1.6;
    color: #222;
    text-align: justify;
}

article h2 {
    font-family: 'Arial', sans-serif;
    font-size: 28px;
    font-weight: 700;
    letter-spacing: 1px;
    text-transform: uppercase;
    border-bottom: 2px solid #2f7a67;
}

article a {
    text-decoration: none;
    font-weight: bold;
    color: #2f7a67;
}

article a:hover {
    text-decoration: underline;
}

Dzięki tym właściwościom możesz stworzyć czytelny, profesjonalny layout tekstowy.

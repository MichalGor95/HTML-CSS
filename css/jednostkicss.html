Rozdział CSS: Jednostki w CSS

W CSS istnieje wiele jednostek - bezwzględnych i względnych. Wybór odpowiedniej jednostki wpływa na responsywność, dostępność i elastyczność layoutu.

1. Podział jednostek w CSS

  • Jednostki bezwzględne - nie zależą od innych elementów (np. px, cm, mm, in, pt, pc)
  • Jednostki względne - zależą od rozmiaru rodzica, okna lub roota (%, em, rem, vw, vh, vmin, vmax, ex, ch)
  • Jednostki specjalne - auto, fit-content, min-content, max-content

W praktyce najczęściej używa się px, %, em, rem, vw, vh i auto.

2. Piksele (px) - jednostka bezwzględna

Jeden piksel to najmniejszy punkt na ekranie. px jest jednostką bezwzględną - nie skaluje się względem innych elementów. 

.box {
    width: 300px;
    font-size: 16px;
    padding: 10px;
}
ZaletyWady
precyzyjna kontrola, stabilnośćnie skaluje się przy powiększeniu czcionki (problem z dostępnością)

Dobra do: obramowań, cieni, małych odstępów, gdy layout ma być sztywny.

3. Procenty (%) - względem rodzica

Procenty są względne - width: 50% oznacza 50% szerokości elementu nadrzędnego. 

.parent {
    width: 800px;
}
.child {
    width: 50%;   /* = 400px */
    padding: 5%;  /* = 5% szerokości rodzica (40px) - nie mylić z font-size! */
}
WłaściwośćWzględem czego?
width, heightszerokość/wysokość rodzica
margin, paddingszerokość rodzica (nawet dla pionowych marginesów!)
font-sizerozmiar czcionki rodzica
line-heightrozmiar czcionki elementu (bieżący)

Procenty świetnie nadają się do responsywnych układów (kolumny, siatki).

4. em - względem rodzica (tekst i nie tylko)

1em to aktualny rozmiar czcionki elementu. Domyślnie w przeglądarkach 1em = 16px. 

body {
    font-size: 16px;
}
p {
    font-size: 1.2em;   /* = 19.2px */
    margin: 1em;        /* = 19.2px (bo względem font-size elementu) */
}

️ Problem z kaskadą em: jeśli masz zagnieżdżone elementy, em się kumuluje. 

div { font-size: 1.2em; }  /* 1.2 × 16px = 19.2px */
div div { font-size: 1.2em; } /* 1.2 × 19.2px = 23.04px */

Używa się go często do margin, padding lub mediów, które mają skalować się z czcionką.

5. rem - względem roota (html)

rem (root em) jest zawsze względem rozmiaru czcionki elementu <html>. Domyślnie 1rem = 16px. 

html {
    font-size: 62.5%;  /* 62.5% z 16px = 10px - ułatwia przeliczanie */
}
h1 {
    font-size: 2.4rem;  /* = 24px */
}
p {
    font-size: 1.6rem;  /* = 16px */
    margin: 1rem;       /* = 10px */
}
Cechaemrem
Bazabieżący elementhtml (root)
Kaskadowośćkumuluje sięnie kumuluje się (stałe)
Zastosowanie>:lokalne odstępy, media skalowalne>:globalne rozmiary tekstu, łatwiejsze utrzymanie

Dobra praktyka: ustawiaj font-size w rem, a margin/padding w rem lub em w zależności od potrzeby.

6. vw i vh - względem okna przeglądarki

1vw = 1% szerokości okna przeglądarki (viewport width).
1vh = 1% wysokości okna przeglądarki (viewport height). 

.hero {
    height: 100vh;      /* pełna wysokość ekranu */
    width: 100vw;       /* pełna szerokość ekranu */
    font-size: 5vw;     /* czcionka skalowana do szerokości okna */
}
JednostkaOpisPrzykład
vw% szerokości viewportuwidth: 50vw - połowa szerokości okna
vh% wysokości viewportuheight: 100vh - cała wysokość ekranu
vmin% z mniejszego wymiaru (min(szer, wys))font-size: 5vmin
vmax% z większego wymiaruwidth: 80vmax

Idealne do: pełnoekranowych sekcji, responsywnych czcionek (ale uwaga na bardzo małe ekrany).

7. auto - inteligentne uzupełnienie

auto to wartość domyślna wielu właściwości. Pozwala przeglądarce automatycznie obliczyć rozmiar lub położenie. 

/* wyśrodkowanie bloku */
.container {
    width: 80%;
    margin-left: auto;
    margin-right: auto;
}

/* element rozciąga się na dostępną szerokość */
.szeroki {
    width: auto;   /* domyślnie - wypełnia rodzica */
}

/* wysokość automatycznie dopasowana do treści */
.elastyczny {
    height: auto;
}
Zastosowanie autoEfekt
margin: 0 auto;wyśrodkowanie w poziomie (przy określonej szerokości)
width: auto;element zajmuje tyle miejsca, ile może (bez nadmiaru)
height: auto;dopasowanie do treści
overflow: auto;dodaje paski przewijania tylko w razie potrzeby

8. Kiedy używać której jednostki? - praktyczne wskazówki

JednostkaNajlepsze zastosowanie
pxobramowania, cienie, drobne odstępy, sztywne elementy
%.\] układy responsywne, siatki, szerokości kolumn
emmarginesy i paddingi skalujące się z czcionką lokalnie
rem._ rozmiary czcionek, odstępy globalne, łatwa dostępność
vw/vh._ pełnoekranowe sekcje, responsywne nagłówki, efekty wizualne
auto._ wyśrodkowanie, elastyczne wypełnianie, domyślne zachowanie

Na egzaminie INF03 często padają pytania o różnicę między em a rem oraz o to, jak zmieni się rozmiar elementu po zmianie font-size rodzica.

9. Przykład - responsywna sekcja z różnymi jednostkami

html {
    font-size: 62.5%; /* 1rem = 10px */
}

* {
    box-sizing: border-box;
}

.hero {
    height: 100vh;           /* pełny ekran */
    background: linear-gradient(135deg, #667eea, #764ba2);
    display: flex;
    align-items: center;
    justify-content: center;
}

.card {
    width: 80%;              /* elastyczna szerokość */
    max-width: 400px;        /* nie większa niż 400px */
    padding: 2rem;           /* 20px */
    background: white;
    border-radius: 1rem;
    text-align: center;
}

.card h2 {
    font-size: 2.4rem;       /* 24px */
    margin-bottom: 1rem;
}

.card p {
    font-size: 1.6rem;       /* 16px */
    line-height: 1.5;
    margin-bottom: 1.5rem;
}

.button {
    display: inline-block;
    padding: 1rem 2rem;
    font-size: 1.4rem;
    background: #2f7a67;
    color: white;
    text-decoration: none;
    border-radius: 0.5rem;
    margin-top: auto;
}

Ten przykład łączy vh, %, rem, px i auto w praktycznym komponencie.

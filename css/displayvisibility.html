Rozdział CSS: Display i widoczność

Właściwość display określa, jak element zachowuje się w układzie strony. visibility steruje widocznością elementu bez wpływu na układ. To kluczowe tematy na egzaminie INF03.

1. Czym jest właściwość display?

Każdy element HTML ma domyślny typ wyświetlania. Możemy go zmienić za pomocą display. Najważniejsze wartości to: block, inline, inline-block, none.

WartośćZachowaniePrzykładowe elementy (domyślnie)
blockzajmuje całą szerokość, rozpoczyna nową linię<div>, <p>, <h1>, <section>
inlinetylko tyle miejsca ile treść, nie łamie linii<span>, <a>, <strong>, <em>
inline-blockjak inline, ale można ustawić szerokość/wysokość<button>, <input> (często)
nonecałkowicie usuwa element z układubrak (całkowicie ukryty)

2. display: block

Element blokowy zajmuje całą dostępną szerokość (100% rodzica) i zawsze zaczyna się od nowej linii. Można mu nadać width, height, margin, padding. 

/* każdy div jest domyślnie block */
div {
    display: block;
    width: 300px;
    margin: 20px auto;
    padding: 15px;
    background: lightblue;
}

/* zamiana elementu inline na block */
span {
    display: block;
    background: orange;
}

Przykładowe elementy blokowe: <div>, <p>, <h1>-<h6>, <ul>, <li>, <section>, <article>, <header>, <footer>.

Zastosowanie: layout strony, kontenery, sekcje.

3. display: inline

Element liniowy zajmuje tylko tyle miejsca, ile potrzebuje jego treść. Nie można ustawić width ani height (ignorowane). Nie rozpoczyna nowej linii - ustawia się obok siebie. 

/* domyślnie span jest inline */
span {
    display: inline;
    background: lightgreen;
    width: 200px;   /* to nie zadziała! */
    height: 50px;   /* to też nie zadziała! */
    margin: 20px;   /* tylko lewy/prawy margin działa */
}

Przykłady: <span>, <a>, <strong>, <em>, <b>, <i>, <img> (choć <img> jest inline, ale można mu dać width/height - to specjalny przypadek).

️ Ograniczenia inline: nie działają width, height, pionowe margin i padding nie wpływają na układ otoczenia.

4. display: inline-block

Łączy cechy inline i block:

  • elementy ustawiają się obok siebie (nie łamią linii)
  • można ustawić width, height, margin, padding (działają poprawnie)
  • odstępy między elementami (białe znaki w HTML) tworzą przerwy - trzeba na to uważać
.inline-block-box {
    display: inline-block;
    width: 150px;
    height: 100px;
    margin: 10px;
    padding: 10px;
    background: coral;
    text-align: center;
}

Świetne do: tworzenia menu poziomego, galerii, przycisków w rzędzie, kart.

5. display: none - całkowite ukrycie

display: none usuwa element z układu strony - znika całkowicie, nie zajmuje miejsca, jakby go nie było. 

.ukryty {
    display: none;
}
/* Element z tą klasą będzie niewidoczny i nie wpłynie na otoczenie */

Ważne: element nie jest renderowany, nie można go kliknąć, nie wchodzi w interakcje.

Zastosowanie: ukrywanie elementów przy media queries, menu mobilne (hamburger), dynamiczne pokazywanie/ukrywanie za pomocą JS.

6. visibility - widoczność z zachowaniem miejsca

Właściwość visibility pozwala ukryć element, ale zachowuje on swoje miejsce w układzie.

WartośćEfekt
visibleelement widoczny (domyślnie)
hiddenelement niewidoczny, ale zajmuje miejsce (jest przezroczysty)
collapsedla tabel - usuwa wiersz/kolumnę; dla innych jak hidden
.visibility-hidden {
    visibility: hidden;
    /* element jest niewidoczny, ale jego miejsce pozostaje puste */
}

.visible {
    visibility: visible;
}

️ Różnica między display: none a visibility: hidden:

Dostępność (screen reader)ignorowanyignorowany (często)

7. Porównanie - kiedy używać?

/* Całkowite ukrycie elementu (znika z układu) */
.element {
    display: none;
}

/* Ukrycie wizualne, ale miejsce zostaje (np. dla animacji, ładowania) */
.element {
    visibility: hidden;
}

/* Element wraca */
.element {
    display: block; /* lub inline, inline-block */
    visibility: visible;
}

Praktyczne zastosowania:

  • display: none - ukrywanie całych sekcji, menu mobilnego, elementów warunkowych.
  • visibility: hidden - gdy potrzebujemy zachować layout (np. placeholdery, stan ładowania, elementy z animacją zanikania).
  • display: block/inline-block - tworzenie przycisków, kart, nawigacji.
  • display: inline - łączenie elementów w tekście (np. ikony z opisem).

8. Przykład - menu poziome z użyciem inline-block

nav ul {
    list-style: none;
    margin: 0;
    padding: 0;
    background: #333;
    text-align: center;
}

nav li {
    display: inline-block;   /* elementy w poziomie */
    margin: 0;
}

nav a {
    display: inline-block;   /* lub block - ale inline-block pozwala na padding */
    padding: 12px 20px;
    color: white;
    text-decoration: none;
}

nav a:hover {
    background: #2f7a67;
}

/* ukrywanie podmenu na małym ekranie */
@media (max-width: 600px) {
    nav li {
        display: block;      /* układ pionowy */
    }
}

Dzięki inline-block elementy menu układają się poziomo, a na małym ekranie zmieniają się na blokowe.

9. Typowe pytania INF03

/* Pytanie: Jaka będzie różnica w wyglądzie? */
span.a { display: block; width: 100px; background: red; }
span.b { display: inline; width: 100px; background: green; }
span.c { display: inline-block; width: 100px; background: blue; }

Odpowiedź:

  • display: block - czerwony prostokąt 100px szerokości, nowa linia.
  • display: inline - zielony pasek tylko wokół tekstu (width zignorowane), brak nowej linii.
  • display: inline-block - niebieski prostokąt 100px, elementy obok siebie.

Zapamiętaj: inline - ignoruje width/height, inline-block - respektuje.

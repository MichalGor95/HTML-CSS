Rozdział 7: Listy w HTML

Listy pozwalają uporządkować informacje w czytelny sposób. Poznaj listy wypunktowane (<ul>), numerowane (<ol>), elementy listy (<li>) oraz zaawansowane techniki, takie jak listy zagnieżdżone i listy definicji.

1. Lista nieuporządkowana <ul> (unordered list)

Lista wypunktowana - kolejność elementów nie ma znaczenia. Każdy element oznaczony jest domyślnie okrągłym punktorem (można zmienić za pomocą CSS).

<ul>
    <li>Chleb</li>
    <li>Mleko</li>
    <li>Jajka</li>
</ul>
  • Chleb
  • Mleko
  • Jajka
Atrybut type (disc, circle, square) jest przestarzały - zamiast tego używaj CSS (list-style-type).

2. Lista uporządkowana <ol> (ordered list)

Lista numerowana - kolejność elementów jest ważna. Domyślnie używane są cyfry arabskie (1, 2, 3...).

<ol>
    <li>Włącz komputer</li>
    <li>Otwórz przeglądarkę</li>
    <li>Wpisz adres strony</li>
</ol>
  1. Włącz komputer
  2. Otwórz przeglądarkę
  3. Wpisz adres strony

Atrybuty <ol>

AtrybutOpisPrzykład
typeOkreśla rodzaj numeracjitype="A" (A, B, C...), type="I" (I, II, III...)
startNumer początkowej wartościstart="5" (zaczyna od 5)
reversedOdwrócona kolejność (malejąco)reversed - znacznik logiczny
 
<ol type="A" start="3">
    <li>Trzecia opcja</li>
    <li>Czwarta opcja</li>
</ol>
  1. Trzecia opcja
  2. Czwarta opcja

3. Element listy <li> (list item)

Znacznik <li> definiuje pojedynczy element wewnątrz <ul> lub <ol>. Może zawierać dowolną treść: tekst, obrazy, linki, a nawet inne listy.

Atrybut value - tylko dla <ol>, zmienia numer bieżącego elementu.
<li value="10">Dziesiąty</li>
Zagnieżdżanie - <li> może zawierać kolejną listę.
Nie używaj <li> poza listami - to niepoprawne składniowo.

4. Listy zagnieżdżone (listy w listach)

Bardzo przydatne do tworzenia hierarchii (menu wielopoziomowe, spisy treści, kategorie). Pamiętaj, że nowa lista musi znajdować się wewnątrz elementu <li>.

<ul>
    <li>Polska
        <ul>
            <li>Warszawa</li>
            <li>Kraków</li>
            <li>Wrocław</li>
        </ul>
    </li>
    <li>Niemcy
        <ul>
            <li>Berlin</li>
            <li>Monachium</li>
        </ul>
    </li>
</ul>
  • Polska
    • Warszawa
    • Kraków
    • Wrocław
  • Niemcy
    • Berlin
    • Monachium
Możesz mieszać typy list: numerowaną wewnątrz wypunktowanej i odwrotnie. Zawsze zachowuj poprawną strukturę.

Poprawne zagnieżdżenie

<ul><li>Poziom 1
  <ol><li>Poziom 2</li></ol>
</li></ul>

Błędne zagnieżdżenie

<ul>
<li>Poziom 1</li>
<ul><li>Błąd (poza li)</li></ul>
</ul>

5. Lista definicji <dl>, <dt>, <dd>

Specjalny typ listy dla par termin - definicja. Nie używa <li>, lecz pary <dt> (term) i <dd> (description).

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language - język znaczników do tworzenia stron.</dd>
    <dt>CSS</dt>
    <dd>Cascading Style Sheets - język stylów.</dd>
</dl>
HTML
HyperText Markup Language - język znaczników do tworzenia stron.
CSS
Cascading Style Sheets - język stylów.
Listy definicji są idealne do słowniczków, metadanych, często pomijane, ale bardzo przydatne.

7. Praktyczne zastosowanie - menu nawigacyjne

Listy są często używane do budowania menu - łatwo je stylować za pomocą CSS (usunięcie punktorów, wyświetlanie w poziomie).

<nav>
    <ul>
        <li><a href="../index.html">Start</a></li>
        <li><a href="oferta.html">Oferta</a></li>
        <li><a href="kontakt.html">Kontakt</a></li>
    </ul>
</nav>
Nawigacja w <nav> z listą to standard dostępności (screen reader). Unikaj samych <div> z linkami.

8. Stylowanie list za pomocą CSS (zarys)

Chociaż to rozdział o HTML, warto wiedzieć, że wygląd punktorów i numeracji definiuje się w CSS:

  • list-style-type - zmienia punktory (disc, circle, square, none, decimal, lower-roman, upper-alpha itd.)
  • list-style-image - własny obrazek jako punktor
  • list-style-position - położenie punktorów (inside/outside)
W HTML5 nie używaj atrybutów type w <ul> ani <li> - to relikt przeszłości. Wszystkie efekty wizualne przenieś do CSS.

9. Przykład złożony - spis treści z podrozdziałami

<h2>Spis treści</h2>
<ol>
    <li>Wprowadzenie
        <ul>
            <li>Czym jest HTML</li>
            <li>Historia</li>
        </ul>
    </li>
    <li>Podstawowe znaczniki
        <ul>
            <li>Nagłówki</li>
            <li>Akapity</li>
        </ul>
    </li>
    <li>Listy
        <ul>
            <li>ul, ol, li</li>
            <li>Zagnieżdżanie</li>
        </ul>
    </li>
</ol>

Spis treści (efekt):

  1. Wprowadzenie
    • Czym jest HTML
    • Historia
  2. Podstawowe znaczniki
    • Nagłówki
    • Akapity
  3. Listy
    • ul, ol, li
    • Zagnieżdżanie

10. Co musisz zapamiętać na egzamin INF03

<ul> - lista wypunktowana (kolejność nieistotna).
<ol> - lista numerowana (ważna kolejność). Atrybuty: type, start, reversed.
<li> - element listy. Może zawierać inne listy.
Zagnieżdżanie - nowa lista zawsze wewnątrz <li>.
<dl>, <dt>, <dd> - lista definicji.
Częste zadanie egzaminacyjne: utwórz menu w postaci listy <ul> z podstronami (zagnieżdżona lista). Pamiętaj o poprawnej składni.

</ul>

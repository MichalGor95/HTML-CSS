Rozdział 17: Nawigacja i struktura strony

Dobra nawigacja to podstawa użytecznej strony internetowej. Poznaj jak tworzyć menu, linkować sekcje (kotwice) oraz jak zbudować typowy układ strony z wykorzystaniem semantycznych znaczników HTML5.

1. Tworzenie menu nawigacyjnego

Menu nawigacyjne najczęściej tworzy się za pomocą listy <ul> wewnątrz znacznika <nav>. Dzięki temu jest semantycznie poprawne i dostępne.

<nav>
    <ul>
        <li><a href="../index.html">Strona główna</a></li>
        <li><a href="oferta.html">Oferta</a></li>
        <li><a href="kontakt.html">Kontakt</a></li>
    </ul>
</nav>
  • Strona główna
  • Oferta
  • Kontakt
  • Menu powinno być spójne na wszystkich podstronach.
  • Aktywny element menu można wyróżnić klasą CSS (np. class="active").
  • W większych serwisach stosuje się menu rozwijane (zagnieżdżone listy).
Umieszczaj menu w znaczniku <nav> - to pomaga czytnikom ekranu i robotom wyszukiwarek.

2. Linkowanie sekcji - kotwice (anchor links)

Kotwice pozwalają na płynne przewijanie do konkretnego fragmentu tej samej strony. Wymagają dwóch elementów: linku z href="#identyfikator" oraz elementu docelowego z atrybutem id="identyfikator".

<!-- Spis treści (linki) -->
<ul>
    <li><a href="#rozdzial1">Rozdział 1</a></li>
    <li><a href="#rozdzial2">Rozdział 2</a></li>
    <li><a href="#rozdzial3">Rozdział 3</a></li>
</ul>

<!-- Miejsca docelowe -->
<section id="rozdzial1">
    <h2>Rozdział 1</h2>
</section>
<section id="rozdzial2">
    <h2>Rozdział 2</h2>
</section>

  • Przejdź do Sekcji B
  • Przejdź do Sekcji C

Aby przewijanie było płynne, w CSS można dodać scroll-behavior: smooth;. Można też użyć kotwic do linkowania z innej strony: <a href="strona.html#sekcja">.

3. Układ typowej strony internetowej

Nowoczesna strona opiera się na semantycznych znacznikach HTML5, takich jak <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>. Oto typowy schemat:

<body>
    <header>
        <div class="logo">Logo</div>
        <nav>...</nav>
    </header>
    
    <main>
        <section>
            <h2>Główna treść</h2>
            <article>...</article>
        </section>
        
        <aside>
            <h3>Sidebar</h3>
            <p>Reklamy, linki, dodatki</p>
        </aside>
    </main>
    
    <footer>
        <p>Stopka &copy;</p>
    </footer>
</body>

Dobra struktura

  • <header> - logo, tytuł, nawigacja.
  • <nav> - główne menu.
  • <main> - unikalna treść (tylko jeden).
  • <section> - logiczne bloki tematyczne.
  • <article> - samodzielne wpisy.
  • <aside> - treść poboczna.
  • <footer> - stopka.

Zła struktura (divitis)

  • <div class="header">
  • <div class="nav">
  • <div class="content">
  • <div class="footer">

4. Przykład kompletnej strony z nawigacją i kotwicami

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Moja strona</title>
    <style>
        html { scroll-behavior: smooth; }
        body { font-family: Arial; margin: 0; padding: 0; }
        header { background: #2f7a67; color: white; padding: 20px; text-align: center; }
        nav { background: #1e5a4a; padding: 10px; text-align: center; }
        nav a { color: white; margin: 0 15px; text-decoration: none; }
        main { max-width: 1000px; margin: 20px auto; padding: 20px; }
        section { margin-bottom: 50px; padding: 20px; border-bottom: 1px solid #ccc; }
        footer { background: #1e2a2a; color: white; text-align: center; padding: 15px; }
    </style>
</head>
<body>
    <header>
        <h1>Moja firma</h1>
    </header>
    <nav>
        <a href="#home">Start</a>
        <a href="#oferta">Oferta</a>
        <a href="#kontakt">Kontakt</a>
    </nav>
    <main>
        <section id="home">
            <h2>Witamy</h2>
            <p>Treść strony głównej...</p>
        </section>
        <section id="oferta">
            <h2>Nasza oferta</h2>
            <p>Opis usług...</p>
        </section>
        <section id="kontakt">
            <h2>Kontakt</h2>
            <p>Telefon: 123 456 789</p>
        </section>
    </main>
    <footer>
        <p>&copy; 2026 Moja firma</p>
    </footer>
</body>
</html>

5. Nawigacja między podstronami - linki względne

W przypadku witryn wielostronicowych linki prowadzą do innych plików HTML. Ważne jest stosowanie poprawnych ścieżek względnych.

PrzykładOpis
<a href="kontakt.html">Kontakt</a>Plik w tym samym katalogu.
<a href="podstrony/oferta.html">Oferta</a>Plik w podfolderze podstrony.
<a href="../index.html">Strona główna</a>Plik w katalogu nadrzędnym (../).
Unikaj bezwzględnych ścieżek lokalnych (typu C:\folder\strona.html) - nie działają na serwerze.

6. Responsywność nawigacji - menu mobilne (zarys)

Współczesne strony często na urządzeniach mobilnych chowają menu pod przycisk "hamburger". Realizuje się to za pomocą CSS (media queries) i JavaScript. Na egzaminie INF03 warto znać podstawy responsywnego menu.

<style>
    @media (max-width: 600px) {
        nav ul { flex-direction: column; }
        .menu-toggle { display: block; }
        nav ul { display: none; }
        nav ul.show { display: flex; }
    }
</style>

7. Nawigacja a dostępność (WCAG)

  • Menu powinno być w pełni nawigowalne za pomocą klawiatury (TAB).
  • Linki powinny mieć sensowne etykiety (unikaj "kliknij tutaj").
  • Można dodać atrybut aria-label lub aria-current="page" dla aktywnego elementu.
  • Kotwice powinny być dobrze widoczne - warto dodać scroll-margin-top (CSS), aby nie chowały się pod stałym nagłówkiem.
<nav>
    <ul>
        <li><a href="../index.html" aria-current="page">Start</a></li>
        <li><a href="oferta.html">Oferta</a></li>
    </ul>
</nav>

8. Typowe błędy i dobre praktyki

Dobre praktyki

  • Stosuj semantyczny <nav> dla menu.
  • Używaj kotwic dla długich stron (np. FAQ).
  • Zapewnij spójność nawigacji na wszystkich podstronach.
  • Wyróżnij aktywny element menu.
  • Linki prowadzące do sekcji na tej samej stronie - używaj href="#id".

Częste błędy

  • Brak znacznika <nav> - sama lista bez semantyki.
  • Kotwice bez id lub zduplikowane identyfikatory.
  • Nieużywanie scroll-behavior: smooth - nagłe przeskoki.
  • Menu nieprzystosowane do urządzeń mobilnych.

Rozdział CSS: Selektory CSS

Selektory wskazują, które elementy HTML mają zostać wystylizowane. Opanowanie selektorów to podstawa skutecznego i elastycznego CSS.

1. Selektor tagu (elementu)

Najprostszy selektor - wybiera wszystkie elementy danego znacznika HTML. 

/* wszystkie akapity */
p {
    color: navy;
    font-size: 16px;
}

/* wszystkie nagłówki h1 */
h1 {
    border-bottom: 2px solid gray;
}

Zaleta: szybki, globalny styl.
️ Uwaga: zmienia wygląd wszystkich elementów tego typu.

2. Selektor klasy (.klasa)

Wybiera elementy posiadające atrybut class o określonej wartości. W CSS poprzedzamy go kropką . 

/* wszystkie elementy z klasą "highlight" */
.highlight {
    background-color: yellow;
    font-weight: bold;
}

/* tylko akapity z klasą "note" */
p.note {
    border-left: 4px solid green;
    padding-left: 12px;
}

Przykład użycia w HTML:

<p class="highlight note">Ten akapit ma dwie klasy</p>
ZapisZnaczenie
.boxwszystkie elementy z klasą "box"
div.boxtylko <div> z klasą "box"
.btn.primaryelement posiadający obie klasy naraz

Klasy są najczęściej używanym selektorem - pozwalają na wielokrotne użycie tego samego stylu.

3. Selektor ID (#id)

Wybiera element o konkretnym atrybucie id. W CSS poprzedzamy go krzyżykiem #. 

/* element o id="menu" */
#menu {
    background-color: #333;
    color: white;
}

/* element o id="logo" */
#logo {
    font-size: 32px;
}

W HTML:

<div id="menu">...</div>
CechaIdKlasa

️ Zasada: id nie może wystąpić więcej niż raz na stronie.

4. Selektor uniwersalny (*)

Wybiera wszystkie elementy na stronie. Używany rzadko, ale bywa przydatny do resetowania marginesów. 

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

/* wszystkie elementy wewnątrz .kontener */
.kontener * {
    border: 1px solid gray;
}

Idealny do resetu CSS na początku arkusza.
️ Może wpływać na wydajność przy bardzo skomplikowanej stronie.

5. Grupowanie selektorów (h1, p)

Gdy kilka selektorów ma mieć te same właściwości, oddzielamy je przecinkami. 

h1, h2, h3 {
    font-family: 'Arial', sans-serif;
    color: #2c3e50;
}

button, .btn, input[type="submit"] {
    border: none;
    cursor: pointer;
}

Dzięki grupowaniu unikamy powtarzania tego samego kodu - to czystszy i łatwiejszy w utrzymaniu CSS.

6. Zagnieżdżenia - relacje między elementami

Za pomocą spacji, znaków >, +, ~ wybieramy elementy w określonym kontekście.

Potomek (spacja)

Wybiera element gdziekolwiek wewnątrz rodzica.

div p {
    color: blue;   /* wszystkie p wewnątrz div, na dowolnym poziomie */
}

Dziecko bezpośrednie (> )

Wybiera tylko bezpośrednie dzieci.

ul > li {
    list-style: square;  /* tylko li, które są bezpośrednio w ul */
}

Sąsiedztwo (+ i ~)

/* element zaraz po poprzednim */
h2 + p {
    font-weight: bold;
}

/* wszystkie p po h2 (na tym samym poziomie) */
h2 ~ p {
    margin-left: 20px;
}

7. Specyficzność selektorów (ważne na INF03!)

Gdy kilka reguł pasuje do tego samego elementu, wygrywa ta o wyższej specyficzności.

/* przykład wygrywania */
p { color: black; }       /* 1 punkt */
.akapit { color: blue; }  /* 10 punktów - wygrywa z p */
#text { color: red; }     /* 100 punktów - najsilniejszy */

Egzamin INF03: często pojawia się pytanie o specyficzność lub o to, który kolor zostanie zastosowany. Zapamiętaj: !important > inline > #id > .klasa > element.

8. Przykład praktyczny - różne selektory w akcji

<!DOCTYPE html>
<style>
    * { box-sizing: border-box; }          /* reset */
    body { font-family: sans-serif; }      /* tag */
    .container { width: 90%; margin: auto; } /* klasa */
    #main-title { color: darkred; }        /* id */
    article p { line-height: 1.5; }        /* zagnieżdżenie */
    .btn, button { padding: 8px 16px; }    /* grupowanie */
</style>

Dzięki łączeniu różnych selektorów tworzysz precyzyjne i czytelne arkusze. W kolejnych rozdziałach poznasz bardziej zaawansowane selektory (atrybutowe, pseudoklasy, pseudoelementy).

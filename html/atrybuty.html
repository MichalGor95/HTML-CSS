Rozdział 19: Atrybuty globalne i praktyczne

Atrybuty globalne to takie, które można zastosować przy każdym znaczniku HTML. Poznaj najważniejsze: class, id, style, title oraz nowoczesne data-*. Są niezbędne do stylowania (CSS) i interakcji (JavaScript).

1. Czym są atrybuty globalne?

Atrybuty globalne mogą wystąpić w każdym znaczniku HTML (od <html> po <div>, <p>, <span> itd.). Definiują dodatkowe właściwości, często wykorzystywane przez CSS i JavaScript.

AtrybutPrzeznaczeniePrzykład
class - klasy CSSGrupowanie elementów do stylowania. Można użyć wielu klas oddzielonych spacją.<p class="uwaga glowny">Tekst</p>
id - unikalny identyfikatorIdentyfikacja pojedynczego elementu (unikalny na stronie). Kotwice, JS.<div id="kontener">...</div>
style - stylowanie inlineBezpośrednie nadanie stylów CSS (unikać, gdy możliwe).<span style="color:red;">czerwony</span>
title - dodatkowy tekst (tooltip)Podpowiedź wyświetlana po najechaniu kursorem.<abbr title="HyperText Markup Language">HTML</abbr>
data-* - atrybuty danychPrzechowywanie dowolnych danych dla JavaScript.<div data-user-id="123"></div>
Inne atrybuty globalne to m.in. hidden, lang, tabindex, dir, accesskey, contenteditable.

2. Atrybut class - klasy CSS

Atrybut class przypisuje elementowi jedną lub więcej klas. Klasy są używane głównie do stylowania CSS (selektor .nazwa) oraz do manipulacji JavaScript (np. dodawanie/usuwanie klas).

<style>
    .warning {
        background-color: #fff2df;
        border-left: 5px solid #e6a017;
        padding: 10px;
    }
    .bold {
        font-weight: bold;
    }
</style>

<div class="warning">Uwaga! To jest ostrzeżenie.</div>
<p class="bold">Pogrubiony tekst.</p>
<p class="warning bold">Ostrzeżenie i pogrubienie jednocześnie.</p>
Uwaga! To jest ostrzeżenie.

Pogrubiony tekst.

Ostrzeżenie i pogrubienie jednocześnie.

  • Nazwa klasy nie może zaczynać się od cyfry (ale może zawierać myślniki i podkreślenia).
  • Wiele klas oddzielamy spacją: class="klasa1 klasa2 klasa3".
  • Ta sama klasa może wystąpić na wielu elementach - to jej główna zaleta.
W CSS do klasy odwołujemy się przez kropkę: .moja-klasa { }. Klasy są rekomendowane zamiast id do stylowania.

3. Atrybut id - unikalny identyfikator

id nadaje elementowi unikalną nazwę w obrębie całej strony. Może być użyty do:

  • Tworzenia kotwic (linków wewnętrznych) - <a href="#sekcja"> i <section id="sekcja">.
  • Selektora CSS - #unikalny { } (wyższa specyficzność niż klasa).
  • Pobierania elementu przez JavaScript - document.getElementById('unikalny').
  • Wiązania etykiety z polem formularza - <label for="pole"> i <input id="pole">.
<h2 id="rozdzial1">Rozdział 1</h2>
<p>Treść rozdziału...</p>
<a href="#rozdzial1">Powrót do rozdziału 1</a>

<label for="email">E-mail:</label>
<input type="email" id="email" name="email">

<div id="unique-demo">Ten div ma unikalne id.</div>
Ten div ma unikalne id (widoczna ramka z CSS).
Ważne: id musi być unikalne w całym dokumencie. Nie można użyć tego samego id dla dwóch różnych elementów.

4. Atrybut style - style inline (bezpośrednie)

Atrybut style pozwala na dodanie CSS bezpośrednio do elementu. Ma najwyższą specyficzność (poza !important), ale jest odradzany w większych projektach, ponieważ miesza warstwy.

<p style="color: #2f7a67; font-size: 18px; margin: 10px;">
    Ten akapit ma style inline.
</p>

Ten akapit ma style inline.

Wady stylów inline

  • Trudne utrzymanie (mieszanie z treścią).
  • Brak możliwości ponownego użycia.
  • Większy rozmiar strony.
  • Trudniejsze nadpisywanie (wysoka specyficzność).

Kiedy (rzadko) używać?

  • Dynamiczne stylowanie z JavaScript (np. element.style.color = 'red').
  • Bardzo proste, jednostronicowe prototypy.
  • W e-mailach HTML (gdzie zewnętrzne CSS często nie działają).
W codziennej pracy priorytetem są klasy CSS i zewnętrzne arkusze stylów. Style inline traktuj jako ostateczność.

5. Atrybut title - podpowiedź (tooltip)

title dodaje tekst podpowiedzi, który pojawia się po najechaniu kursorem na element (zwykle po krótkiej chwili). Poprawia użyteczność (UX).

<abbr title="HyperText Markup Language">HTML</abbr>
<span title="To jest ważna informacja">️</span>
<button title="Kliknij, aby zapisać">Zapisz</button>
HTML ️

Najedź na mnie kursorem

Atrybut title nie zastępuje <label> dla pól formularzy - dla dostępności używaj label.

6. Atrybuty data-* - przechowywanie danych

data-* to grupa atrybutów (np. data-user-id, data-role, data-status) pozwalająca na przechowywanie dowolnych danych w elemencie. Są często używane w JavaScript do przekazywania informacji.

<div data-user-id="12345" data-role="admin" data-status="aktywny">
    Jan Kowalski
</div>

<button data-action="delete" data-id="7">Usuń</button>

<script>
    const user = document.querySelector('[data-user-id]');
    console.log(user.dataset.userId); // "12345"
    console.log(user.dataset.role);   // "admin"
</script>
Jan Kowalski (dane: data-user-id="12345", data-role="admin")

W konsoli JavaScript można odczytać dataset.userId.

  • Nazwa po data- może zawierać tylko małe litery, cyfry i myślniki.
  • W JavaScript dostęp do atrybutu: element.dataset.nazwa (myślniki zamieniane na camelCase: data-user-id → userId).
  • Popularne w frameworkach (np. React, Vue) oraz do testów automatycznych.
Nie używaj data-* do przechowywania wrażliwych danych (haseł, tokenów) - są widoczne w kodzie źródłowym.

8. Przykład kompleksowy - wszystkie atrybuty w akcji

<div class="karta produkt" id="produkt-123" data-kategoria="elektronika">
    <h3 title="Kliknij, aby zobaczyć szczegóły">Smartfon XYZ</h3>
    <p class="cena" style="font-weight: bold; color: #2f7a67;">1499 zł</p>
    <button data-id="123" class="btn-zakup">Kup</button>
</div>

<style>
    .karta {
        border: 1px solid #ddd;
        border-radius: 12px;
        padding: 15px;
        margin: 10px 0;
    }
    .cena {
        font-size: 1.2em;
    }
    [data-kategoria="elektronika"] {
        background-color: #f9f5eb;
    }
</style>

<script>
    document.querySelector('.btn-zakup').addEventListener('click', function() {
        const produktId = this.dataset.id;
        alert('Dodano produkt o ID ' + produktId);
    });
</script>

9. Dobre praktyki dotyczące atrybutów globalnych

Dobre praktyki

  • Używaj nazw klas zgodnych z przeznaczeniem (np. .warning, .btn-primary).
  • Identyfikatorów id używaj oszczędnie - tylko gdy potrzebujesz linku lub JS.
  • Unikaj stylów inline - preferuj klasy i zewnętrzne CSS.
  • Atrybut title dodawaj dla ikon, skrótów, akronimów - poprawia UX.
  • data-* stosuj do przechowywania danych dla JavaScript (nie do stylów).

Częste błędy

  • Używanie tego samego id dla kilku elementów (niepoprawne).
  • Używanie zbyt wielu klas (komplikuje kod).
  • Pomijanie title w elementach interaktywnych (utrata podpowiedzi).
  • Mieszanie stylów inline i klas - chaos.
  • Przechowywanie wrażliwych danych w data-*.

Rozdział CSS: Responsywność

Responsywność to umiejętność dostosowywania się strony do różnych rozmiarów ekranu - od telefonów komórkowych, przez tablety, aż po szerokie monitory. Kluczowymi narzędziami są media queries, breakpointy, strategia mobile-first oraz elastyczne układy (flexbox/grid). To obowiązkowy temat na egzaminie INF03.

1. Czym jest responsywność?

Responsywny Web Design (RWD) to podejście, w którym strona automatycznie dostosowuje swój wygląd i układ do szerokości okna przeglądarki. Dzięki temu strona jest użyteczna na każdym urządzeniu.

  • płynne siatki (procenty, fr, flexbox, grid)
  • elastyczne obrazy (max-width: 100%)
  • media queries - reguły warunkowe dla różnych rozmiarów
  • viewport meta tag - kontrolowanie skali na urządzeniach mobilnych
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Bez tego meta tagu strony na telefonach będą wyglądać jak pomniejszone wersje desktopowe.

2. @media - zapytania medialne

Media queries pozwalają stosować style tylko w określonych warunkach, np. przy maksymalnej szerokości ekranu. 

/* Dla ekranów o szerokości do 768px */
@media (max-width: 768px) {
    body {
        font-size: 14px;
    }
    .sidebar {
        display: none;
    }
}

/* Dla ekranów powyżej 1200px */
@media (min-width: 1200px) {
    .container {
        max-width: 1140px;
        margin: 0 auto;
    }
}

/* Zakres między 768px a 1024px (tablety) */
@media (min-width: 768px) and (max-width: 1024px) {
    .card {
        width: 50%;
    }
}
WarunekZnaczenie
max-width: 768pxdla urządzeń o szerokości ≤ 768px (telefony, małe tablety)
min-width: 768pxdla urządzeń o szerokości ≥ 768px (tablety i większe)
orientation: portraitpionowa orientacja ekranu
orientation: landscapepozioma orientacja
min-resolution: 192dpiekrany o wysokiej rozdzielczości (Retina)

Można też łączyć z screen (ekrany) lub print (druk).

3. Breakpointy - punkty przełomowe

Breakpointy to konkretne wartości szerokości, przy których zmienia się układ strony. Najczęściej używa się kilku standardowych punktów.

Typ urządzeniaSzerokość (częste breakpointy)
telefony (portret)< 576px
telefony (landscape) / małe tablety576px - 768px
tablety768px - 992px
desktopy992px - 1200px
duże ekrany> 1200px
/* Popularne breakpointy w praktyce */
/* Telefony */
@media (max-width: 576px) { ... }

/* Tablety pionowe */
@media (min-width: 577px) and (max-width: 768px) { ... }

/* Tablety poziome / małe laptopy */
@media (min-width: 769px) and (max-width: 992px) { ... }

/* Desktopy */
@media (min-width: 993px) and (max-width: 1200px) { ... }

/* Duże ekrany */
@media (min-width: 1201px) { ... }

Breakpointy warto dobierać w oparciu o treść, a nie tylko urządzenia. Często używa się 576px, 768px, 992px, 1200px (zgodnie z Bootstrapem).

4. Strategia mobile-first

Mobile-first oznacza projektowanie najpierw dla najmniejszych ekranów (telefonów), a następnie dodawanie stylów dla większych urządzeń za pomocą min-width. Dzięki temu strona jest lżejsza i lepiej działa na urządzeniach mobilnych. 

/* Styl domyślny - dla telefonów (brak media query) */
.container {
    display: flex;
    flex-direction: column;
    gap: 10px;
}
.card {
    width: 100%;
}

/* Dla tabletów i większych */
@media (min-width: 768px) {
    .container {
        flex-direction: row;
        flex-wrap: wrap;
    }
    .card {
        width: calc(50% - 10px);
    }
}

/* Dla desktopów */
@media (min-width: 992px) {
    .card {
        width: calc(33.333% - 10px);
    }
}
Ten kolor zmienia się na pomarańczowy gdy ekran ma szerokość ≤ 600px (przykład)

(zmniejsz okno przeglądarki, aby zobaczyć)

Zalety mobile-first: lepsza wydajność na urządzeniach mobilnych, mniej kodu, naturalne stopniowe ulepszanie (progressive enhancement).

5. Elastyczne układy - bez media queries

Responsywność można osiągnąć także bez media queries, używając elastycznych jednostek i właściwości CSS.

  • Procenty - width: 100%, width: 50%
  • max-width - img { max-width: 100%; }
  • Jednostki vw/vh - względem viewportu
  • Flexbox z wrap - flex-wrap: wrap + flex-basis
  • Grid z auto-fit / auto-fill - repeat(auto-fit, minmax(200px, 1fr))
  • Funkcje clamp(), min(), max() - płynne skalowanie
/* Elastyczna siatka z flexbox */
.flex-grid {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}
.flex-item {
    flex: 1 1 250px;  /* minimum 250px, rośnie jeśli miejsce */
}

/* Elastyczna siatka z grid (bez media queries) */
.grid-auto {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 20px;
}

/* Płynna czcionka */
h1 {
    font-size: clamp(24px, 5vw, 48px);
}

clamp(min, preferred, max) - idealne do responsywnych czcionek i odstępów.

6. Przykład - nawigacja mobile-first

<style>
    /* domyślnie (telefon) - menu pionowe */
    .nav {
        display: flex;
        flex-direction: column;
        gap: 10px;
        background: #333;
        padding: 15px;
    }
    .nav a {
        color: white;
        text-decoration: none;
        padding: 8px;
        text-align: center;
        border-radius: 5px;
    }
    .nav a:hover {
        background: #2f7a67;
    }

    /* tablet i większe - menu poziome */
    @media (min-width: 768px) {
        .nav {
            flex-direction: row;
            justify-content: space-around;
        }
        .nav a {
            flex: 1;
        }
    }

    /* desktop - większe odstępy */
    @media (min-width: 1200px) {
        .nav {
            justify-content: flex-start;
            gap: 30px;
            padding-left: 50px;
        }
        .nav a {
            flex: 0 0 auto;
        }
    }
</style>

7. Responsywne obrazy i filmy

/* Podstawowa zasada */
img, video, iframe {
    max-width: 100%;
    height: auto;
}

/* Dla filmów YouTube - zachowanie proporcji 16:9 */
.video-container {
    position: relative;
    padding-bottom: 56.25%; /* 9/16 */
    height: 0;
    overflow: hidden;
}
.video-container iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
}

8. Viewport meta tag - niezbędnik RWD

<meta name="viewport" content="width=device-width, initial-scale=1.0">
ParametrZnaczenie
width=device-widthszerokość układu równa szerokości ekranu urządzenia
initial-scale=1.0początkowy poziom powiększenia = 1 (bez zoomu)
user-scalable=yes/noczy użytkownik może powiększać (dostępność: lepiej yes)

️ Bez tego tagu przeglądarki mobilne domyślnie ustawiają szerokość ok. 980px i skalują stronę.

9. Ćwiczenia INF03 - responsywność

Pytanie 1: Jaka jest różnica między @media (max-width: 600px) a @media (min-width: 600px)?

Odpowiedź: max-width stosuje style dla ekranów o szerokości ≤ 600px. min-width dla ekranów ≥ 600px (strategia mobile-first).

Pytanie 2: Dlaczego warto używać mobile-first?

Odpowiedź: Ponieważ większość ruchu pochodzi z urządzeń mobilnych, strona ładuje się szybciej, a style są stopniowo ulepszane dla większych ekranów.

Pytanie 3: Jak sprawić, by obraz nie był większy od swojego kontenera?

img {
    max-width: 100%;
    height: auto;
}

Pytanie 4: Co daje flex-wrap: wrap w responsywności?

Odpowiedź: Pozwala elementom flex przenosić się do nowych wierszy, gdy brakuje miejsca, tworząc responsywny układ.

10. Podsumowanie - dobra praktyka RWD

  • Zawsze dodawaj meta viewport
  • Stosuj elastyczne jednostki (%, fr, vw, rem, clamp)
  • Używaj max-width: 100% dla obrazów i multimediów
  • Projektuj z podejściem mobile-first (style domyślne dla telefonów)
  • Definiuj breakpointy tam, gdzie układ przestaje działać (content-driven)
  • Testuj na rzeczywistych urządzeniach lub w narzędziach deweloperskich
/* Przykład kompletnego, responsywnego kontenera */
.container {
    width: 100%;
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 20px;
    box-sizing: border-box;
}

/* Dla dużych ekranów zwiększamy padding */
@media (min-width: 1400px) {
    .container {
        padding: 0 40px;
    }
}

Rozdział CSS: Flexbox

Flexbox (Flexible Box Layout) to nowoczesny model układu, który ułatwia tworzenie elastycznych, responsywnych struktur. Jest często używany do budowy menu, kart, pasków narzędzi i wielu innych komponentów. Na egzaminie INF03 flexbox pojawia się regularnie.

1. Czym jest Flexbox?

Flexbox to system jednokierunkowego układu - elementy układają się w wiersz lub kolumnę. Działa na dwóch poziomach: kontener flex (rodzic) i elementy flex (dzieci).

  • display: flex - przekształca kontener w flex container
  • flex-direction - kierunek układania (wiersz / kolumna)
  • justify-content - wyrównanie w głównej osi
  • align-items - wyrównanie w poprzecznej osi
  • gap - odstępy między elementami
  • flex-wrap - zawijanie elementów
  • order - zmiana kolejności wizualnej
  • align-self - nadpisanie align-items dla pojedynczego elementu

2. display: flex - tworzenie kontenera flex

Ustawienie display: flex na rodzicu sprawia, że jego bezpośrednie dzieci stają się elementami flex i układają się w jednym wierszu (domyślnie). 

.kontener {
    display: flex;
}

Ustawia rozmieszczenie elementów wzdłuż osi poprzecznej (prostopadłej do głównej). Działa, gdy elementy mają różną wysokość (w wierszu) lub szerokość (w kolumnie).

6. gap - odstępy między elementami

gap ustawia odstępy między elementami flex (oraz grid) - działa zarówno w pionie, jak i poziomie. Jest to wygodniejsza alternatywa dla margin na dzieciach. 

.kontener {
    display: flex;
    gap: 20px;        /* 20px odstępu między wszystkimi elementami */
    gap: 10px 20px;   /* odstęp pionowy 10px, poziomy 20px (przy wrap) */
}

7. flex-wrap - zawijanie elementów

Domyślnie elementy flex próbują zmieścić się w jednym wierszu. flex-wrap pozwala im zawijać się na kolejne wiersze, gdy brakuje miejsca.

8. order - zmiana kolejności wizualnej

Właściwość order (ustawiana na elementach flex) zmienia kolejność wyświetlania bez zmiany HTML. Domyślnie wszystkie elementy mają order: 0. Elementy o niższej wartości order pojawiają się wcześniej. 

.item1 { order: 2; }
.item2 { order: 1; }
.item3 { order: 3; }
/* Kolejność: item2, item1, item3 */
order: 2,1,3 (oryginalnie 1,2,3)
1 (order:2)
2 (order:1)
3 (order:3)

Zastosowanie: zmiana układu w media queries, układanie elementów na małych ekranach.

9. align-self - nadpisanie dla pojedynczego elementu

align-self działa jak align-items, ale tylko dla jednego elementu flex. Może przyjmować te same wartości: auto, flex-start, flex-end, center, stretch, baseline. 

.kontener {
    display: flex;
    align-items: center;   /* domyślnie wszystkie wyśrodkowane */
    height: 150px;
}
.special {
    align-self: flex-end;  /* ten element będzie na dole */
}
align-self: flex-end (środkowy element)
domyślny

Pozwala na indywidualne wyrównanie elementu bez zmiany dla rodzeństwa.

11. Przykład - poziome menu z flexbox

<style>
    .nav {
        display: flex;
        justify-content: space-between;
        align-items: center;
        background: #333;
        padding: 0 20px;
        flex-wrap: wrap;
        gap: 10px;
    }
    .nav-links {
        display: flex;
        gap: 20px;
    }
    .nav-links a {
        color: white;
        text-decoration: none;
        padding: 12px 0;
    }
    .logo {
        color: white;
        font-size: 1.5rem;
        font-weight: bold;
    }
    @media (max-width: 600px) {
        .nav {
            flex-direction: column;
            text-align: center;
        }
        .nav-links {
            flex-direction: column;
            gap: 5px;
        }
    }
</style>

12. Ćwiczenia INF03

Pytanie 1: Co robi justify-content: space-between?

Odpowiedź: Rozkłada elementy równomiernie, pierwszy na początku, ostatni na końcu, równe odstępy między nimi.

Pytanie 2: Jak wyśrodkować element w kontenerze flex w pionie i poziomie?

.kontener {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 300px;
}

Pytanie 3: Różnica między align-items a align-self?

Odpowiedź: align-items działa na całym kontenerze i dotyczy wszystkich dzieci. align-self nadpisuje to ustawienie dla pojedynczego elementu.

Pytanie 4: Czy gap działa we wszystkich przeglądarkach?

Odpowiedź: Tak, wszystkie nowoczesne przeglądarki wspierają gap dla flexbox od kilku lat.

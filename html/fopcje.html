Rozdział 13: Formularze - wybór opcji

Formularze to nie tylko pola tekstowe. Poznaj znaczniki do wyboru opcji: checkbox (wybór wielokrotny), radio (wybór jednej opcji), listę rozwijaną <select> z <option> oraz wielowierszowe pole tekstowe <textarea>.

1. Checkbox - pole wyboru (wielokrotny wybór)

<input type="checkbox"> - pozwala użytkownikowi zaznaczyć lub odznaczyć opcję. Można wybrać wiele checkboxów jednocześnie.

<label>
    <input type="checkbox" name="zainteresowania" value="sport"> Sport
</label>
<label>
    <input type="checkbox" name="zainteresowania" value="muzyka"> Muzyka
</label>
<label>
    <input type="checkbox" name="zainteresowania" value="technologia" checked> Technologia (domyślnie zaznaczony)
</label>
  • Atrybut checked - domyślnie zaznaczony.
  • Wiele checkboxów może mieć tę samą nazwę name - wtedy po stronie serwera otrzymujemy tablicę wartości.
  • Każdy checkbox powinien mieć swój value - to wartość wysyłana do serwera (domyślnie "on", jeśli brak value).
Jeśli używasz wielu checkboxów z tą samą nazwą, na serwerze (np. PHP) odczytasz je jako tablicę: $_POST['zainteresowania'].

2. Radio - przycisk opcji (wybór jednej opcji)

<input type="radio"> - pozwala wybrać tylko jedną opcję z grupy. Wszystkie radio w grupie muszą mieć taką samą nazwę (name).

<label>
    <input type="radio" name="plec" value="k"> Kobieta
</label>
<label>
    <input type="radio" name="plec" value="m"> Mężczyzna
</label>
<label>
    <input type="radio" name="plec" value="i" checked> Inne
</label>
W grupie radio tylko jedna opcja może być zaznaczona. Jeśli nie ustawisz checked, żadna nie będzie domyślnie wybrana - użytkownik musi sam wybrać.

3. <select> i <option> - lista rozwijana

<select> tworzy listę rozwijaną (lub listę wielokrotnego wyboru). <option> definiuje poszczególne elementy listy.

<select name="miasto">
    <option value="waw">Warszawa</option>
    <option value="krk" selected>Kraków</option>
    <option value="wro">Wrocław</option>
    <option value="gdansk">Gdańsk</option>
</select>

Atrybuty <select>

size - liczba widocznych opcji (domyślnie 1). size="5"
multiple - umożliwia wybór wielu opcji (z Ctrl lub Shift).
disabled - cała lista nieaktywna.
<select name="kolory" multiple size="3">
    <option value="czerwony">Czerwony</option>
    <option value="zielony">Zielony</option>
    <option value="niebieski">Niebieski</option>
</select>

Przytrzymaj Ctrl (Cmd), aby wybrać wiele opcji.

Opcję domyślnie wybraną w <select> oznaczamy atrybutem selected w odpowiednim <option>.

4. Grupowanie opcji - <optgroup>

W rozwijanych listach można grupować opcje za pomocą <optgroup label="nazwa grupy">.

<select name="produkt">
    <optgroup label="Elektronika">
        <option>Słuchawki</option>
        <option>Myszka</option>
    </optgroup>
    <optgroup label="Odzież">
        <option>Koszulka</option>
        <option>Spodnie</option>
    </optgroup>
</select>

5. <textarea> - wielowierszowe pole tekstowe

Używane do dłuższych wypowiedzi, komentarzy, opisów. Różni się od <input> możliwością zmiany rozmiaru i wieloma liniami.

<label for="komentarz">Komentarz:</label>
<textarea id="komentarz" name="komentarz" rows="5" cols="40" placeholder="Wpisz swoją opinię..."></textarea>

rows - liczba widocznych wierszy tekstu.
cols - liczba widocznych kolumn (szerokość).
placeholder - podpowiedź (jak w input).
maxlength - maksymalna liczba znaków.
wrap - zawijanie tekstu (soft/hard).
Tekst początkowy w <textarea> umieszcza się między tagami, a nie w atrybucie value. Np. <textarea>Domyślny tekst</textarea>.

7. Przykład kompleksowego formularza z różnymi opcjami wyboru

<form action="zapisz.php" method="post">
    <fieldset>
        <legend>Ankieta użytkownika</legend>
        
        <p>Płeć:</p>
        <label><input type="radio" name="plec" value="k"> Kobieta</label>
        <label><input type="radio" name="plec" value="m"> Mężczyzna</label>
        
        <p>Zainteresowania:</p>
        <label><input type="checkbox" name="zainteresowania[]" value="sport"> Sport</label>
        <label><input type="checkbox" name="zainteresowania[]" value="muzyka"> Muzyka</label>
        <label><input type="checkbox" name="zainteresowania[]" value="film"> Film</label>
        
        <p>Miasto:</p>
        <select name="miasto">
            <option value="waw">Warszawa</option>
            <option value="krk">Kraków</option>
            <option value="wro">Wrocław</option>
        </select>
        
        <p>Dodatkowe uwagi:</p>
        <textarea name="uwagi" rows="4" cols="50" placeholder="Twoje uwagi...</textarea>
        
        <button type="submit">Wyślij</button>
    </fieldset>
</form>

8. Dobre praktyki dla pól wyboru

Dobre praktyki

  • Zawsze grupuj radio tą samą nazwą name.
  • Używaj <label> z odpowiednim for lub opakowując input - zwiększa klikalność.
  • Dla checkboxów z wielokrotnym wyborem stosuj nazwy tablicowe (np. name="zain[]" w PHP).
  • Ustawiaj domyślną wartość (checked lub selected) tam, gdzie to pomaga użytkownikowi.
  • Dla <textarea> ustal odpowiednie rows i cols lub użyj CSS.

Częste błędy

  • Radio z różnymi nazwami - można wybrać więcej niż jedną opcję.
  • Brak value w checkbox/radio - serwer otrzyma domyślne "on".
  • Używanie <textarea> z atrybutem value (to nie działa).
  • Brak etykiet - utrudniona dostępność.

10. Co musisz zapamiętać na egzamin INF03

checkbox - wybór wielokrotny, atrybut checked.
radio - wybór jednej opcji z grupy (ta sama nazwa).
<select> - lista rozwijana, atrybuty size, multiple.
<option> - element listy, atrybut selected.
<optgroup> - grupowanie opcji w select.
<textarea> - wielowierszowe pole, atrybuty rows, cols.
Egzaminatorzy często wymagają stworzenia formularza z różnymi polami wyboru - pamiętaj o poprawnych atrybutach name i value oraz grupowaniu radio. 
<!-- Przykład wzorcowego fragmentu z wyborem opcji -->
<fieldset>
    <legend>Preferencje</legend>
    <label><input type="radio" name="kontakt" value="email" checked> E-mail</label>
    <label><input type="radio" name="kontakt" value="telefon"> Telefon</label>
    
    <label><input type="checkbox" name="newsletter" value="tak"> Zapisz do newslettera</label>
    
    <select name="kraj">
        <option value="pl" selected>Polska</option>
        <option value="de">Niemcy</option>
    </select>
    
    <textarea name="uwagi" rows="3" cols="30" placeholder="Twoje uwagi..."></textarea>
</fieldset>

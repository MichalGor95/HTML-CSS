Rozdział 12: Pola tekstowe w formularzach

Szczegółowe omówienie pól <input> typu text, email, password oraz atrybutów placeholder i required. Dodatkowo poznasz inne przydatne atrybuty: pattern, minlength, maxlength, value i walidację HTML5.

1. <input type="text"> - standardowe pole tekstowe

Pole do wprowadzania dowolnego tekstu (jedna linia). Najczęściej używane dla imienia, miasta, tytułu, wyszukiwanej frazy.

<label for="imie">Imię:</label>
<input type="text" id="imie" name="imie" placeholder="Wpisz swoje imię">
maxlength - maksymalna liczba znaków.
<input type="text" maxlength="50">
minlength - minimalna liczba znaków (HTML5).
<input type="text" minlength="3">
size - widoczna szerokość pola (w znakach) - raczej używaj CSS.
value - początkowa wartość pola.
<input type="text" value="Jan Kowalski">

2. <input type="email"> - pole adresu e-mail

Specjalne pole do adresów e-mail. Przeglądarka sprawdza poprawność składni (np. obecność @ i domeny). Na urządzeniach mobilnych klawiatura pokazuje @ i kropkę.

<label for="email">E-mail:</label>
<input type="email" id="email" name="email" required>
  • Automatyczna walidacja - przy niepoprawnym adresie przeglądarka blokuje wysłanie formularza i pokazuje komunikat.
  • Można użyć atrybutu multiple - pozwala na wpisanie kilku adresów oddzielonych przecinkami.
Walidacja HTML5 jest po stronie klienta - dla bezpieczeństwa zawsze weryfikuj dane również po stronie serwera.

3. <input type="password"> - pole hasła

Znaki wpisywane przez użytkownika są maskowane (kropki lub gwiazdki). Nie ukrywa to danych przed serwerem - wysyłane są w czystej postaci (przy POST warto użyć HTTPS).

<label for="haslo">Hasło:</label>
<input type="password" id="haslo" name="haslo" required minlength="8">
Pole hasła nie szyfruje danych podczas transmisji. Zawsze używaj HTTPS, aby zabezpieczyć dane logowania.

4. Atrybut placeholder - podpowiedź wewnątrz pola

placeholder - tekst przykładowy (podpowiedź) wyświetlany wewnątrz pola, znika po rozpoczęciu pisania. Nie zastępuje etykiety <label> - służy tylko jako dodatkowa wskazówka.

<input type="text" placeholder="np. Jan Kowalski">
<input type="email" placeholder="jan@example.com">
Nie używaj samego placeholder zamiast <label> - to utrudnia dostępność (po rozpoczęciu pisania podpowiedź znika).

5. Atrybut required - pole obowiązkowe

required - oznacza, że pole musi być wypełnione przed wysłaniem formularza. Przeglądarka nie pozwoli na submisję, pokazując komunikat błędu.

<input type="text" name="imie" required>
<input type="email" name="email" required>


Próbując wysłać puste pole, przeglądarka zablokuje submisję.

Atrybut required nie zabezpiecza przed pustymi łańcuchami znaków (spacjami) - do tego potrzebna jest walidacja po stronie serwera.

6. Dodatkowe atrybuty walidujące (pattern, minlength, maxlength)

AtrybutOpisPrzykład
pattern Wyrażenie regularne, któremu musi odpowiadać wartość pola. Rozszerzona walidacja. pattern="[A-Za-z]{3,}" - co najmniej 3 litery
minlength Minimalna liczba znaków. minlength="3"
maxlength Maksymalna liczba znaków. maxlength="50"
size (prezentacyjny) Szerokość pola (w znakach), lepiej użyć CSS. size="30" 
<!-- Kod pocztowy: 2 cyfry, myślnik, 3 cyfry -->
<input type="text" name="kod" pattern="[0-9]{2}-[0-9]{3}" placeholder="00-000" required>
<!-- Hasło: min. 8 znaków -->
<input type="password" name="haslo" minlength="8" required>

7. Atrybut value - domyślna wartość pola

Atrybut value ustawia początkową zawartość pola. Można go dynamicznie zmieniać JavaScriptem lub użyć do wstępnego wypełnienia formularza.

<input type="text" name="kraj" value="Polska">
<input type="text" name="miasto" value="Warszawa">

Atrybut readonly - pole tylko do odczytu (nie można edytować).

8. Pola tylko do odczytu i wyłączone (readonly, disabled)

  • readonly - wartość jest widoczna i wysyłana, ale użytkownik nie może jej zmienić.
  • disabled - pole jest nieaktywne, nie można go edytować, a jego wartość nie jest wysyłana do serwera.
<input type="text" value="stała wartość" readonly>
<input type="text" value="wyłączone" disabled>

9. Przykład formularza z różnymi polami tekstowymi

<form action="rejestracja.php" method="post">
    <fieldset>
        <legend>Dane osobowe</legend>
        <label>Imię: <input type="text" name="imie" required placeholder="Jan" minlength="2"></label><br>
        <label>Nazwisko: <input type="text" name="nazwisko" required placeholder="Kowalski"></label><br>
        <label>E-mail: <input type="email" name="email" required placeholder="jan@example.com"></label><br>
        <label>Hasło: <input type="password" name="haslo" required minlength="8" placeholder="min. 8 znaków"></label><br>
        <label>Kod pocztowy: <input type="text" name="kod" pattern="[0-9]{2}-[0-9]{3}" placeholder="00-000"></label><br>
        <button type="submit">Zarejestruj</button>
    </fieldset>
</form>

10. Walidacja HTML5 - komunikaty błędów

Przeglądarki pokazują własne komunikaty walidacyjne. Można je dostosować za pomocą JavaScript lub atrybutu title, ale domyślnie są wystarczające.

Dobre praktyki

  • Używaj odpowiedniego typu (email, tel, url, number).
  • Stosuj required dla kluczowych pól.
  • Dodawaj placeholder jako przykładowy format.
  • Stosuj pattern do niestandardowych formatów (PESEL, kod pocztowy).
  • Zawsze waliduj dane po stronie serwera (weryfikacja końcowa).

Częste błędy

  • Pomijanie name - dane nie zostaną wysłane.
  • Używanie placeholder zamiast <label>.
  • Zbyt restrykcyjne pattern (uniemożliwia poprawne dane).
  • Poleganie wyłącznie na walidacji klienckiej.

12. Co musisz zapamiętać na egzamin INF03

type="text" - zwykłe pole tekstowe (imię, miasto).
type="email" - walidacja adresu e-mail, specjalna klawiatura.
type="password" - maskowanie znaków.
placeholder - przykładowy tekst (nie zastępuje label!).
required - pole obowiązkowe.
pattern - walidacja przez regex.
minlength / maxlength - ograniczenie długości.
Egzaminatorzy często dają zadanie: stwórz formularz rejestracji z polami tekstowymi, e-mailem, hasłem, walidacją i placeholderami. Pamiętaj o poprawnym użyciu required i odpowiednich typach input. 
<!-- Wzorcowy fragment formularza (pola tekstowe) -->
<label>Login: <input type="text" name="login" required minlength="4" maxlength="20"></label>
<label>E-mail: <input type="email" name="email" required placeholder="przyklad@domena.pl"></label>
<label>Hasło: <input type="password" name="haslo" required minlength="8"></label>

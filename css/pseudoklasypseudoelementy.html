Rozdział CSS: Pseudoklasy i pseudoelementy

Pseudoklasy i pseudoelementy pozwalają stylizować elementy w określonych stanach lub dodawać wirtualne fragmenty do strony bez zmiany HTML. To bardzo przydatne narzędzie na egzaminie INF03 i w praktyce.

1. Czym są pseudoklasy?

Pseudoklasa definiuje stan elementu lub jego szczególną pozycję w drzewie DOM. Zapisywane są z dwukropkiem: :nazwa.

  • :hover - gdy kursor znajduje się nad elementem
  • :focus - gdy element ma fokus (np. pole formularza)
  • :active - w momencie kliknięcia (aktywacji)
  • :first-child - pierwsze dziecko rodzica
  • :last-child, :nth-child(), :not() i wiele innych

2. :hover - po najechaniu myszką

Pseudoklasa :hover aktywuje się, gdy użytkownik najedzie kursorem na element. Najczęściej używana do przycisków, linków, kart. 

/* Zmiana koloru linku po najechaniu */
a:hover {
    color: #2f7a67;
    text-decoration: underline;
}

/* Przycisk z efektem powiększenia */
.button:hover {
    background-color: #1e5a4a;
    transform: scale(1.05);
    transition: all 0.3s ease;
}

/* Karta z cieniem po najechaniu */
.card:hover {
    box-shadow: 0 8px 20px rgba(0,0,0,0.15);
}

Zastosowanie: interaktywne przyciski, linki, galerie, karty produktów.

3. :focus - element z fokusem

Pseudoklasa :focus dotyczy elementów, które mogą otrzymać fokus (klawiatura lub kliknięcie) - głównie pól formularza (<input>, <textarea>), przycisków i linków. 

/* Podświetlenie pola input po kliknięciu/tabie */
input:focus {
    border-color: #2f7a67;
    outline: none;
    box-shadow: 0 0 0 3px rgba(47,122,103,0.2);
}

/* Link z fokusem (dla dostępności klawiaturowej) */
a:focus {
    outline: 2px solid #2f7a67;
    outline-offset: 2px;
}

/* Przycisk z fokusem */
button:focus {
    background-color: #1e5a4a;
}

Ważne dla dostępności: nie usuwaj całkowicie outline bez dodania alternatywnego stylu. Osoby poruszające się klawiaturą potrzebują wizualnego wskaźnika fokusu.

4. :active - w momencie kliknięcia

Pseudoklasa :active działa w krótkim momencie między naciśnięciem a puszczeniem przycisku myszy. Stosowana do efektu „wciśnięcia” przycisku. 

/* Efekt wciśnięcia przycisku */
button:active {
    transform: translateY(2px);
    box-shadow: none;
}

/* Link w trakcie klikania */
a:active {
    color: darkred;
}

Kolejność stylowania linków (ważna!):
:link → :visited → :hover → :focus → :active
(pamiętaj o tym na egzaminie - w praktyce często wystarczy :hover i :active).

5. :first-child - pierwsze dziecko rodzica

Wybiera element, który jest pierwszym dzieckiem swojego rodzica. Przydatne do nadawania specjalnych stylów pierwszemu akapitowi, pierwszemu elementowi listy. 

/* Pierwszy akapit w kontenerze */
article p:first-child {
    font-size: 1.2em;
    font-weight: bold;
}

/* Pierwszy element listy */
li:first-child {
    border-top: none;
    margin-top: 0;
}

/* Specjalny styl dla pierwszego diva w sekcji */
section div:first-child {
    background-color: #f0f7f4;
}

Podobne pseudoklasy:

PseudoklasaZnaczenie
:first-childpierwsze dziecko rodzica
:last-childostatnie dziecko rodzica
:nth-child(n)n-te dziecko (np. :nth-child(2), :nth-child(even))
:first-of-typepierwszy element danego typu wśród rodzeństwa
:nth-of-type(n)n-ty element danego typu

6. Czym są pseudoelementy?

Pseudoelementy tworzą wirtualne elementy, które nie istnieją w HTML. Służą do dodawania treści przed lub po elemencie, stylowania pierwszej litery, pierwszej linii itp. Zapisywane z podwójnym dwukropkiem: ::nazwa (w CSS3; starsze wersje używają :).

  • ::before - dodaje treść przed zawartością elementu
  • ::after - dodaje treść po zawartości elementu
  • ::first-letter - pierwsza litera
  • ::first-line - pierwsza linia tekstu
  • ::selection - zaznaczony tekst

7. ::before - przed elementem

Pseudoelement ::before wstawia treść przed zawartością wybranego elementu. Wymaga właściwości content. 

/* Dodanie ikony przed linkiem */
.link-pdf::before {
    content: " ";
}

/* Dodanie cudzysłowu przed cytatem */
blockquote::before {
    content: "„";
    font-size: 2em;
    color: #2f7a67;
    margin-right: 5px;
}

/* Dodanie etykiety "Nowość!" przed produktem */
.product.new::before {
    content: " NOWOŚĆ ";
    background-color: #ff6600;
    color: white;
    font-size: 0.7em;
    padding: 2px 6px;
    border-radius: 10px;
    margin-right: 8px;
}

8. ::after - po elemencie

Pseudoelement ::after wstawia treść po zawartości elementu. Również wymaga content. 

/* Dodanie strzałki po linku (dla menu) */
.menu-item a::after {
    content: " →";
    font-size: 0.8em;
}

/* Dodanie etykiety "zniżka" po cenie */
.price::after {
    content: " (-20%)";
    color: red;
    font-size: 0.8em;
}

/* Czyszczenie floatów (clearfix) */
.clearfix::after {
    content: "";
    display: table;
    clear: both;
}
PseudoelementDziałaniePrzykład zastosowania
::beforetreść przed elementemikony, dekoracje, cytaty
::aftertreść po elemencieczyszczenie float, dodatkowe etykiety, strzałki
::first-letterpierwsza literakapitaliki w artykułach
::first-linepierwsza liniaspecjalne formatowanie wstępu

9. Praktyczne przykłady łączenia pseudoklas i pseudoelementów

Przycisk z efektem hover + after

.btn {
    background: #2f7a67;
    color: white;
    padding: 10px 20px;
    border: none;
    cursor: pointer;
    position: relative;
    transition: all 0.3s;
}

.btn:hover {
    background: #1e5a4a;
    padding-right: 30px;
}

.btn:hover::after {
    content: " →";
    position: absolute;
    margin-left: 5px;
}

Lista z niestandardowymi znacznikami

.custom-list li {
    list-style: none;
    margin-bottom: 8px;
}

.custom-list li::before {
    content: "";
    color: #2f7a67;
    margin-right: 8px;
    font-weight: bold;
}

Wyróżnienie pierwszego akapitu w artykule

article p:first-child::first-letter {
    font-size: 3em;
    font-weight: bold;
    color: #2f7a67;
    float: left;
    margin-right: 8px;
    line-height: 0.8;
}

Na egzaminie INF03 często pojawia się pytanie o rozróżnienie. Pamiętaj: pseudoklasa = stan (np. najechany), pseudoelement = wirtualny fragment (np. przed tekstem).

11. Ćwiczenia egzaminacyjne

Pytanie 1: Co zrobi poniższy kod?

li:first-child {
    color: red;
}

Odpowiedź: Pierwszy element listy w każdym <ul> lub <ol> będzie miał czerwony kolor.

Pytanie 2: Jaka jest różnica między :first-child a :first-of-type?

Odpowiedź: :first-child wybiera pierwsze dziecko niezależnie od typu. :first-of-type wybiera pierwszy element danego typu wśród rodzeństwa.

Pytanie 3: Co jest nieprawidłowego w tym kodzie?

div::before {
    display: block;
    width: 100px;
}

Odpowiedź: Brak właściwości content - pseudoelementy ::before i ::after wymagają content (nawet jeśli puste: content: "";).

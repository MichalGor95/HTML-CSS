Rozdział CSS: Obrazy i multimedia

Obrazy i multimedia to nieodłączna część nowoczesnych stron. CSS pozwala kontrolować ich rozmiary, proporcje, dopasowanie do kontenerów oraz efekty wizualne. Responsywność obrazków jest kluczowa dla działania strony na różnych urządzeniach.

1. Rozmiary obrazów - width i height

Obrazy w HTML mają własne wymiary. Za pomocą CSS możemy je zmieniać, ale trzeba uważać na zniekształcenia. 

/* Stałe wymiary - może zniekształcić */
img {
    width: 300px;
    height: 200px;
}

/* Tylko szerokość - wysokość skaluje się automatycznie (zachowanie proporcji) */
img.responsive {
    width: 100%;
    height: auto;
}

/* Maksymalna szerokość - obraz nie przekroczy oryginalnych rozmiarów */
img.max-width {
    max-width: 100%;
    height: auto;
}
WłaściwośćDziałanieKiedy używać?
width: 100%; height: auto;skalowanie proporcjonalne do szerokości rodzicaresponsywne obrazy w elastycznych kontenerach
max-width: 100%; height: auto;nie przekracza oryginalnego rozmiaru, ale skaluje się w dółnajbezpieczniejszy dla responsywności
width: 300px; height: 200px;,\] sztywne wymiary (może zniekształcić)gdy dokładnie potrzebujemy takich wymiarów (np. galeria)

Złota zasada: dla responsywnych obrazków używaj max-width: 100%; height: auto;

2. object-fit - dopasowanie obrazu w kontenerze

Gdy ustawimy stałe width i height dla obrazu, może on zostać zniekształcony. Właściwość object-fit określa, jak obraz ma być dopasowany do zadanego prostokąta. 

/* Wszystkie obrazy w kontenerze o stałych wymiarach */
.gallery img {
    width: 200px;
    height: 200px;
    object-fit: cover;    /* wypełnia całość, przycina (domyślnie) */
}

/* Inne wartości */
.fit-fill {
    object-fit: fill;      /* zniekształca, wypełnia całkowicie */
}
.fit-contain {
    object-fit: contain;   /* cały obraz mieści się w kontenerze (mogą być paski) */
}
.fit-cover {
    object-fit: cover;     /* wypełnia, przycina, zachowuje proporcje */
}
.fit-none {
    object-fit: none;      /* oryginalny rozmiar, przycięcie */
}
.fit-scale-down {
    object-fit: scale-down; /* wybiera mniejsze z none lub contain */
}
WartośćEfektPrzykład zastosowania
coverwypełnia cały kontener, przycina krawędziegalerie zdjęć, tła, awatary
containcały obraz widoczny, mogą być paski po bokachprezentacja produktów, gdy ważny jest cały obraz
fillrozciąga do wymiarów kontenera (zniekształca)rzadko - tylko gdy efekt nie przeszkadza
none.\] oryginalny rozmiar, przycięciegdy chcemy pokazać fragment dużego obrazu
scale-downjak none lub contain - mniejszy z nichbezpieczne wyświetlanie bez powiększenia

object-fit działa na <img>, <video>. Dla elementów tła (background-image) używa się background-size: cover/contain.

3. border-radius - zaokrąglanie rogów obrazów

Zaokrąglenie rogów sprawia, że obrazy stają się bardziej nowoczesne i przyjazne. Można uzyskać również kształt koła. 

/* Lekko zaokrąglony obraz */
img.rounded {
    border-radius: 12px;
}

/* Obraz w kształcie koła (avatar) */
img.avatar {
    border-radius: 50%;
    width: 100px;
    height: 100px;
    object-fit: cover;
}

/* Różne zaokrąglenia */
img.custom {
    border-radius: 30% 10% 30% 10%;  /* górny-lewy, górny-prawy, dolny-prawy, dolny-lewy */
}

/* Połączenie z innymi efektami */
img.card-img {
    border-radius: 12px 12px 0 0;    /* tylko górne rogi */
}

️ Uwaga: border-radius: 50% działa poprawnie tylko gdy obraz jest kwadratowy. W przeciwnym razie powstanie elipsa.

4. Responsywne obrazki - techniki

Obraz responsywny to taki, który dostosowuje się do rozmiaru ekranu, nie wylewa poza kontener i ładuje odpowiednią wersję (np. mniejszą na telefonie).

Metoda CSS - max-width

img {
    max-width: 100%;
    height: auto;
    display: block; /* usuwa odstęp pod obrazem */
}

Obrazy w kontenerze - picture element (HTML)

<picture>
    <source media="(max-width: 600px)" srcset="maly.jpg">
    <source media="(max-width: 1200px)" srcset="sredni.jpg">
    <img src="duzy.jpg" alt="opis">
</picture>

Atrybut srcset - różne rozdzielczości

<img src="obraz.jpg"
     srcset="obraz-480w.jpg 480w,
             obraz-800w.jpg 800w,
             obraz-1200w.jpg 1200w"
     sizes="(max-width: 600px) 480px, 800px"
     alt="opis">

Na egzaminie INF03 często pytają o różnicę między max-width: 100% a width: 100%. max-width pozwala obrazowi być mniejszym niż oryginał, width: 100% zawsze rozciąga do pełnej szerokości rodzica.

5. Dodatkowe techniki dla obrazów

Obraz jako tło z cover/contain

.bg-hero {
    background-image: url('tlo.jpg');
    background-size: cover;   /* lub contain */
    background-position: center;
    background-repeat: no-repeat;
    height: 100vh;
}

Efekt przyciemnienia na obrazie (overlay)

.img-container {
    position: relative;
    display: inline-block;
}
.img-container::after {
    content: "";
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: rgba(0,0,0,0.4);
    border-radius: inherit;
}

Filtry na obrazach

img.grayscale {
    filter: grayscale(100%);
}
img.blur {
    filter: blur(5px);
}
img.brightness {
    filter: brightness(1.2);
}
img:hover {
    filter: brightness(0.8);
    transition: 0.3s;
}

6. Multimedia - stylowanie video

Elementy <video> i <iframe> (np. YouTube) również można stylować. Dla responsywności często stosuje się technikę "intrinsic ratio". 

/* Responsywne wideo (zachowanie proporcji 16:9) */
.video-container {
    position: relative;
    padding-bottom: 56.25%; /* 9/16 = 0.5625 */
    height: 0;
    overflow: hidden;
}
.video-container iframe,
.video-container video {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
}

/* Bezpośrednie stylowanie video */
video {
    max-width: 100%;
    height: auto;
    border-radius: 12px;
}

8. Ćwiczenia INF03

Pytanie 1: Co zrobi object-fit: cover dla obrazu o wymiarach 200x200px?

Odpowiedź: Obraz wypełni cały kontener, zostanie przycięty (zachowując proporcje) tak, aby nie było pustych pasków.

Pytanie 2: Jak sprawić, by obraz był okrągły (avatar)?

img {
    width: 100px;
    height: 100px;
    border-radius: 50%;
    object-fit: cover;
}

Pytanie 3: Jaka jest różnica między width: 100% a max-width: 100% na obrazie?

Odpowiedź: width: 100% zawsze ustawia szerokość na 100% rodzica (może powiększyć obraz). max-width: 100% pozwala obrazowi być mniejszym niż oryginał, ale nie większym.

Pytanie 4: Jakie wartości object-fit zachowują proporcje obrazu?

Odpowiedź: cover, contain, scale-down (oraz none jeśli obraz nie jest skalowany).

Rozdział CSS: Wprowadzenie do CSS

CSS (Cascading Style Sheets) to język stylów, który nadaje wygląd stronom HTML. Bez niego strony byłyby tylko czarno-białym tekstem na szarym tle.

1. Czym jest CSS?

CSS pozwala oddzielić treść od prezentacji. Dzięki niemu możesz zmienić kolor, czcionkę, układ, animacje i wiele więcej.

  • Stylizacja tekstu (kolor, rozmiar, krój)
  • Układ strony (marginesy, pozycjonowanie, flex, grid)
  • Efekty wizualne (cienie, gradienty, animacje)
  • Responsywność (dostosowanie do ekranów)

CSS działa na zasadzie kaskadowości - style mogą się nakładać, a najważniejsze jest to, co zdefiniowane najbliżej elementu lub z najwyższym priorytetem.

2. Składnia CSS

Podstawowa reguła CSS składa się z selektora, właściwości i wartości. 

selektor {
    właściwość: wartość;
}

Przykład:

p {
    color: blue;
    font-size: 16px;
}
Element Znaczenie Przykład
Selektor Określa, które elementy HTML zostaną wystylizowane h1, .klasa, #id
Właściwość Cecha, którą zmieniamy (np. kolor, rozmiar) color, margin, background
Wartość Konkretne ustawienie danej właściwości red, 20px, none

3. Komentarze w CSS

Komentarze są ignorowane przez przeglądarkę - służą do opisywania kodu. Przydają się przy większych projektach. 

/* To jest komentarz w CSS */
p {
    color: green; /* kolor akapitów - można zmienić później */
}

Można nimi również tymczasowo „wyłączać” fragmenty stylów.

4. Gdzie pisać CSS?

Istnieją trzy podstawowe sposoby dołączenia CSS do strony HTML.

CSS inline (w linii)

Style wpisuje się bezpośrednio w znaczniku HTML za pomocą atrybutu style.

<p style="color: red; font-weight: bold;">To jest czerwony akapit</p>

Wady: miesza strukturę z wyglądem, trudno utrzymać większą stronę.

CSS wewnętrzny (w sekcji <style>)

Reguły CSS umieszcza się w znaczniku <style> wewnątrz <head>.

<head>
    <style>
        body {
            background-color: #f0f0f0;
        }
        h1 {
            color: navy;
        }
    </style>
</head>

Zaleta: lepsze niż inline. Wada: style nie są współdzielone między wieloma stronami.

CSS zewnętrzny (osobny plik .css)

Reguły zapisuje się w pliku style.css i podłącza za pomocą <link>.

<link rel="stylesheet" href="../style.css">

Zalety: jeden plik CSS może obsłużyć wiele podstron, łatwiejsze utrzymanie, szybsze ładowanie (cache).

Metoda Zastosowanie Priorytet (kaskada)
inline pojedynczy, unikalny element najwyższy
wewnętrzny <style> jedna konkretna strona średni
zewnętrzny .css cała witryna (najlepsza praktyka) najniższy (może być nadpisany)

Wskazówka na INF03: w praktyce egzaminacyjnej najczęściej wymagany jest zewnętrzny arkusz stylów. Pamiętaj o poprawnym podaniu ścieżki (np. css/style.css).

5. Kaskadowość i dziedziczenie

CSS to kaskadowe arkusze stylów. Oznacza to, że:

  • Style mogą być dziedziczone (np. rodzica na dziecko).
  • Jeśli kilka reguł pasuje do tego samego elementu, wygrywa ta z wyższą specyficznością (np. #id jest ważniejszy niż .klasa).
  • Reguła z !important ma najwyższy priorytet (unikać nadużywania).
/* Przykład specyficzności */
p { color: black; }           /* 1 punkt */
.akapit { color: blue; }      /* 10 punktów - wygrywa */
#specjalny { color: red; }    /* 100 punktów - najsilniejszy */

Dzięki kaskadzie możesz tworzyć czytelne i łatwe w utrzymaniu arkusze.

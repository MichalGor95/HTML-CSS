Rozdział CSS: Formularze w CSS

Formularze to kluczowy element interaktywnych stron. CSS pozwala całkowicie zmienić ich wygląd - od pól tekstowych, przez przyciski, aż po rozwijane listy. Dobre stylowanie formularzy poprawia użyteczność i estetykę.

1. Dlaczego stylować formularze?

Domyślne formularze różnią się między przeglądarkami i często wyglądają staroświecko. Stylowanie CSS pozwala:

  • uzyskać spójny wygląd na każdej przeglądarce
  • poprawić czytelność i dostępność
  • dostosować formularz do identyfikacji wizualnej strony
  • stworzyć efekty interaktywne (hover, focus)

2. Stylowanie pól input

Pola tekstowe, hasła, e-mail, liczby - wszystkie <input> można stylować wspólnie lub osobno za pomocą selektorów atrybutów. 

/* Wszystkie pola input, textarea i select */
input, textarea, select {
    width: 100%;
    padding: 12px 15px;
    margin: 8px 0;
    border: 1px solid #ddd;
    border-radius: 8px;
    font-size: 16px;
    transition: all 0.3s ease;
}

/* Różne typy input - osobne style */
input[type="text"],
input[type="email"],
input[type="password"] {
    background-color: #f9f9f9;
}

input[type="checkbox"],
input[type="radio"] {
    width: auto;
    margin-right: 8px;
    transform: scale(1.1);
}

input[type="color"] {
    padding: 4px;
    height: 50px;
}

input[type="range"] {
    padding: 0;
}
Selektor atrybutu Opis
input[type="text"] tylko pola tekstowe
input[type="email"] pola email
input[type="number"] pola numeryczne
input[type="date"] daty
input[type="search"] pole wyszukiwania

3. Stylowanie textarea

<textarea> pozwala na wielowierszowy tekst. Można zmienić jego rozmiar, wygląd i możliwość ręcznego przeciągania (resize). 

textarea {
    width: 100%;
    padding: 12px;
    border: 1px solid #ccc;
    border-radius: 8px;
    font-family: Arial, sans-serif;
    font-size: 14px;
    resize: vertical;    /* pozwala na zmianę wysokości, ale nie szerokości */
    min-height: 100px;
}

/* Wyłączenie możliwości zmiany rozmiaru */
textarea.no-resize {
    resize: none;
}

/* Płynne powiększanie */
textarea.elastic {
    resize: vertical;
    overflow-y: auto;
}

Wartości resize: none, both, horizontal, vertical. Domyślnie w wielu przeglądarkach jest both.

4. Stylowanie przycisków (button)

Przyciski - <button>, <input type="submit"> - można stylować podobnie, ale warto dodać efekty interaktywne. 

/* Przyciski podstawowe */
button, 
input[type="submit"],
input[type="reset"],
input[type="button"] {
    background-color: #2f7a67;
    color: white;
    border: none;
    padding: 12px 24px;
    border-radius: 8px;
    font-size: 16px;
    cursor: pointer;
    transition: all 0.3s ease;
}

/* Efekty hover i focus */
button:hover,
input[type="submit"]:hover {
    background-color: #1e5a4a;
    transform: translateY(-2px);
    box-shadow: 0 4px 8px rgba(0,0,0,0.1);
}

button:active,
input[type="submit"]:active {
    transform: translateY(0);
}

/* Przycisk wtórny (outline) */
.btn-secondary {
    background: transparent;
    border: 2px solid #2f7a67;
    color: #2f7a67;
}
.btn-secondary:hover {
    background: #2f7a67;
    color: white;
}

/* Przycisk nieaktywny */
button:disabled {
    background: #ccc;
    cursor: not-allowed;
    transform: none;
}

5. Stylowanie select (lista rozwijana)

<select> jest trudniejszy do stylowania, ale można zmienić jego podstawowe cechy. Pełna personalizacja wymaga często JavaScript lub niestandardowych rozwiązań. 

select {
    width: 100%;
    padding: 12px 15px;
    border: 1px solid #ddd;
    border-radius: 8px;
    background-color: white;
    font-size: 16px;
    cursor: pointer;
    appearance: none;          /* usuwa domyślną strzałkę (wymaga własnej strzałki) */
}

/* Dla Firefox'a */
select::-ms-expand {
    display: none;
}

/* Opcje wewnątrz select - ograniczone możliwości */
select option {
    padding: 10px;
    background-color: white;
    color: #333;
}

Aby całkowicie dostosować select, często używa się bibliotek lub tworzy własny dropdown z divów i JS.

6. Stylowanie placeholdera

Pseudoklasa ::placeholder pozwala zmienić kolor, rozmiar i styl tekstu pomocniczego w polach. 

/* Dla nowoczesnych przeglądarek */
input::placeholder,
textarea::placeholder {
    color: #aaa;
    font-style: italic;
    font-size: 14px;
}

/* Dla starszych przeglądarek (webkit) */
input::-webkit-input-placeholder {
    color: #aaa;
}

/* Dostosowanie dla różnych stanów */
input:focus::placeholder {
    color: #2f7a67;
    opacity: 0.7;
}

Placeholder nie zastępuje etykiety (<label>) - to tylko podpowiedź. Zawsze używaj <label> dla dostępności.

7. :focus - podświetlenie aktywnego pola

Pseudoklasa :focus jest kluczowa dla użyteczności - pokazuje użytkownikowi, które pole jest aktywne (zwłaszcza przy nawigacji klawiaturą). 

input:focus,
textarea:focus,
select:focus {
    border-color: #2f7a67;
    outline: none;
    box-shadow: 0 0 0 3px rgba(47,122,103,0.2);
}

/* Inny efekt - zmiana tła */
input:focus {
    background-color: #f0fff8;
}

/* Dla przycisków */
button:focus {
    outline: 2px solid #2f7a67;
    outline-offset: 2px;
}

Dostępność: nigdy nie usuwaj całkowicie outline bez dodania alternatywnego wizualnego wskaźnika (np. box-shadow lub border).

8. Inne przydatne pseudoklasy dla formularzy

Pseudoklasa Znaczenie Przykład
:required pole obowiązkowe input:required { border-left: 3px solid red; }
:optional pole opcjonalne input:optional { background: #f9f9f9; }
:valid pole z poprawną wartością (np. email) input:valid { border-color: green; }
:invalid pole z niepoprawną wartością input:invalid { border-color: red; }
:disabled pole wyłączone input:disabled { background: #eee; }
:checked zaznaczony checkbox/radio input:checked + label { font-weight: bold; } 
/* Wizualne wyróżnienie pól obowiązkowych */
input:required {
    border-left: 4px solid #e74c3c;
}

/* Walidacja w czasie rzeczywistym */
input:valid {
    border-color: #2ecc71;
}
input:invalid {
    border-color: #e74c3c;
}

/* Styl dla zaznaczonego checkboxa + etykiety */
input[type="checkbox"]:checked + label {
    color: #2f7a67;
    text-decoration: underline;
}

10. Ćwiczenia INF03

Pytanie 1: Jak zmienić kolor tekstu podpowiedzi w polu input?

input::placeholder {
    color: gray;
}

Pytanie 2: Dlaczego nie należy usuwać outline bez alternatywy?

Odpowiedź: Zapewnia to widoczność fokusu dla osób nawigujących klawiaturą (dostępność).

Pytanie 3: Jak zapobiec rozciąganiu się textarea na szerokość?

textarea {
    resize: vertical; /* lub none */
}

Pytanie 4: Która pseudoklasa pozwala zmienić wygląd zaznaczonego pola checkbox?

Odpowiedź: :checked - np. input:checked + label.

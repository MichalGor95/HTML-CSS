Rozdział CSS: Listy i tabele

Listy i tabele to często używane elementy do prezentacji danych. CSS pozwala precyzyjnie kontrolować ich wygląd - od znaczników list po obramowania i kolorowanie komórek tabel.

1. Stylowanie list - podstawy

Listy HTML (<ul> - nienumerowana, <ol> - numerowana) można stylować za pomocą specjalnych właściwości.

  • list-style-type - rodzaj znacznika (kółko, kwadrat, cyfra, litera itp.)
  • list-style-position - położenie znacznika (wewnątrz lub na zewnątrz)
  • list-style-image - własny obrazek jako znacznik

2. list-style-type - rodzaj znacznika

Określa wygląd punktorów lub numerów. 

/* Lista nienumerowana (ul) */
ul.kropki {
    list-style-type: disc;      /* domyślnie - wypełnione kółko */
}
ul.kwadraty {
    list-style-type: square;    /* kwadrat */
}
ul.kolka {
    list-style-type: circle;    /* puste kółko */
}
ul.brak {
    list-style-type: none;      /* bez znaczników - często do menu */
}

/* Lista numerowana (ol) */
ol.cyfry {
    list-style-type: decimal;           /* 1, 2, 3... */
}
ol.litery {
    list-style-type: lower-alpha;       /* a, b, c... */
}
ol.duzeLITERY {
    list-style-type: upper-alpha;       /* A, B, C... */
}
ol.rzymskie {
    list-style-type: lower-roman;       /* i, ii, iii... */
}
Wartość Efekt dla <ul> Efekt dla <ol>
disc wypełnione kółko -
circle puste kółko -
square kwadrat -
decimal - 1, 2, 3
lower-alpha - a, b, c
upper-alpha - A, B, C
lower-roman - i, ii, iii
none brak znacznika brak numeru

Częsta praktyka: usuwanie znaczników w menu (list-style-type: none) i dodawanie własnych za pomocą background-image lub pseudoelementów.

3. list-style-position - położenie znacznika

Określa, czy znacznik znajduje się wewnątrz czy na zewnątrz bloku listy. 

/* Domyślne - outside (znacznik poza blokiem tekstu) */
ul.outside {
    list-style-position: outside;
}

/* inside - znacznik wewnątrz, tekst zawija pod znacznik */
ul.inside {
    list-style-position: inside;
}
Wartość Zachowanie Kiedy używać?
outside znacznik na lewo od tekstu, tekst wyrównany domyślnie, standardowe listy
inside znacznik traktowany jak część tekstu (wcięcie mniejsze) kompaktowe listy, menu responsywne

Różnica jest subtelna, ale przy długich liniach wpływa na czytelność.

4. Skrócona właściwość list-style

Łączy list-style-type, list-style-position i list-style-image. 

li {
    list-style: square inside;       /* typ + pozycja */
}

ul {
    list-style: none;                /* żadnych znaczników */
}

5. Tabele - podstawy stylowania

Tabele HTML mają specyficzne właściwości CSS, które pomagają kontrolować odstępy, obramowania i układ komórek.

6. border-collapse - łączenie ramek tabeli

Właściwość border-collapse decyduje, czy komórki tabeli mają mieć oddzielne ramki, czy połączone (sklejone). 

/* Oddzielne ramki (domyślnie) */
table.separate {
    border-collapse: separate;
    border-spacing: 2px;    /* odstęp między ramkami */
}

/* Połączone ramki - najczęściej używane */
table.collapse {
    border-collapse: collapse;
}
Wartość Efekt Typowe zastosowanie
separate ramki komórek są oddzielone (z odstępem) rzadziej, gdy chcemy efekt "przerw"
collapse ramki są połączone - sąsiednie ramki się nakładają standard - czyste, proste tabele 
/* Typowa tabela z border-collapse */
table {
    border-collapse: collapse;
    width: 100%;
}

th, td {
    border: 1px solid #ddd;
    padding: 8px 12px;
    text-align: left;
}

7. Stylowanie tabel - praktyczne techniki

Nagłówek tabeli (th)

th {
    background-color: #2f7a67;
    color: white;
    font-weight: bold;
}

Przemieniane wiersze (zebra)

/* co drugi wiersz */
tbody tr:nth-child(even) {
    background-color: #f9f9f9;
}
tbody tr:nth-child(odd) {
    background-color: #fff;
}

Efekt hover na wierszu

tbody tr:hover {
    background-color: #e8f0fe;
    cursor: pointer;
}

Wyrównanie tekstu

th {
    text-align: center;
}
td.numer {
    text-align: right;
}
td {
    vertical-align: middle;  /* pionowe wyrównanie (top, middle, bottom) */
}

8. Pełny przykład - stylowa tabela danych

Kod CSS dla przykładowej tabeli:

.data-table {
    width: 100%;
    border-collapse: collapse;
    font-family: Arial, sans-serif;
    box-shadow: 0 0 10px rgba(0,0,0,0.1);
}
.data-table caption {
    caption-side: top;
    margin-bottom: 10px;
    font-weight: bold;
    font-size: 1.2em;
}
.data-table th,
.data-table td {
    border: 1px solid #ddd;
    padding: 12px 15px;
    text-align: left;
}
.data-table th {
    background-color: #2f7a67;
    color: white;
    font-weight: bold;
}
.data-table tr:nth-child(even) {
    background-color: #f2f2f2;
}
.data-table tr:hover {
    background-color: #e6f7f2;
}
.data-table td:first-child {
    font-weight: bold;
}

Struktura HTML takiej tabeli:

<table class="data-table">
    <caption>Lista kursów</caption>
    <thead>
        <tr><th>ID</th><th>Nazwa kursu</th><th>Poziom</th><th>Cena</th></tr>
    </thead>
    <tbody>
        <tr><td>1</td><td>HTML i CSS</td><td>Podstawowy</td><td>249 zł</td></tr>
        <tr><td>2</td><td>JavaScript</td><td>Średniozaawansowany</td><td>349 zł</td></tr>
        <tr><td>3</td><td>React</td><td>Zaawansowany</td><td>449 zł</td></tr>
    </tbody>
</table>

9. Inne przydatne właściwości dla tabel

Właściwość Opis Przykład
border-spacing odstęp między komórkami (gdy border-collapse: separate) border-spacing: 5px;
empty-cells czy pokazywać ramki pustych komórek empty-cells: hide;
caption-side pozycja tytułu tabeli (top/bottom) caption-side: bottom;
table-layout fixed - szybsze renderowanie, fixed widths table-layout: fixed; 
/* Szybka tabela z równymi kolumnami */
table {
    table-layout: fixed;
    width: 100%;
}
th, td {
    width: 25%;  /* każda kolumna równa */
}

10. Typowe pytania INF03

Pytanie 1: Jak usunąć punktor listy, ale zachować wcięcie? 

ul {
    list-style-type: none;
    padding-left: 20px;  /* zachowuje wcięcie */
}

Pytanie 2: Co da border-collapse: collapse?

Odpowiedź: sprawi, że sąsiednie ramki komórek połączą się w jedną, eliminując podwójne krawędzie.

Pytanie 3: Jak zrobić efekt "zebry" w tabeli? 

tr:nth-child(even) {
    background-color: #f0f0f0;
}

Rozdział CSS: Pozycjonowanie

Pozycjonowanie w CSS określa, jak elementy są rozmieszczane na stronie. Dzięki niemu możesz umieszczać elementy w konkretnych miejscach, tworzyć nawigacje przyklejone do ekranu, nakładki czy menu kontekstowe. To jeden z ważniejszych tematów na egzaminie INF03.

1. Czym jest pozycjonowanie?

Właściwość position określa typ pozycjonowania elementu. Może przyjmować wartości: static (domyślnie), relative, absolute, fixed, sticky.

Dla elementów pozycjonowanych (innych niż static) można użyć właściwości top, right, bottom, left do przesunięcia.

2. position: static

Wartość domyślna. Element pozostaje w normalnym przepływie dokumentu. Właściwości top/right/bottom/left oraz z-index nie działają. 

/* Domyślnie każdy element ma position: static */
div {
    position: static;
    top: 20px;   /* ignorowane */
    left: 20px;  /* ignorowane */
}

Nie trzeba go ustawiać - to wartość początkowa. Używa się go czasem, aby "odjąć" pozycjonowanie.

3. position: relative

Element pozostaje w normalnym przepływie, ale można go przesunąć względem jego normalnej pozycji za pomocą top/right/bottom/left. Inne elementy nie reagują na to przesunięcie (zachowują oryginalne miejsce). 

.relative-box {
    position: relative;
    top: 20px;    /* przesuwa w dół o 20px od normalnej pozycji */
    left: 30px;   /* przesuwa w prawo o 30px */
    background: orange;
}

Ważne: Element z relative staje się punktem odniesienia dla pozycjonowanych absolutnie dzieci (jeśli nie mają własnego pozycjonowanego rodzica).

4. position: absolute

Element zostaje wyrwany z normalnego przepływu. Nie wpływa na układ innych elementów. Jest pozycjonowany względem najbliższego przodka z pozycjonowaniem (nie static) lub względem <html>, jeśli takiego nie ma. 

.kontener {
    position: relative;  /* punkt odniesienia */
}
.absolute-box {
    position: absolute;
    bottom: 10px;
    right: 10px;
    background: red;
}

Ten kontener ma position: relative, więc absolute jest względem niego.

Zastosowania: menu rozwijane, dymki, nakładki, modale, przyciski w rogu kontenera.

5. position: fixed

Element jest pozycjonowany względem okna przeglądarki (viewport). Pozostaje w tym samym miejscu podczas przewijania strony. Zostaje wyrwany z przepływu. 

.fixed-button {
    position: fixed;
    bottom: 20px;
    right: 20px;
    background: #2980b9;
    padding: 10px 15px;
    border-radius: 8px;
    z-index: 100;
}
(przykład: przycisk fixed pojawiłby się w rogu okna)

Zastosowania: przycisk "Do góry", stałe menu, pasek zgody na cookies, czat. ️ Uwaga: na urządzeniach mobilnych fixed może sprawiać problemy - ale to już zaawansowane.

6. position: sticky

Mieszanka relative i fixed. Element zachowuje się jak relative, ale gdy użytkownik przewinie stronę do określonego progu (top, bottom itp.), "przykleja się" do ekranu jak fixed w obrębie rodzica. 

.sticky-header {
    position: sticky;
    top: 0;
    background: #8e44ad;
    color: white;
    padding: 10px;
}

7. top, right, bottom, left - przesunięcia

Właściwości te określają odległość od odpowiedniej krawędzi elementu pozycjonowanego do krawędzi elementu odniesienia (czyli najbliższego pozycjonowanego przodka dla absolute, viewport dla fixed, lub normalnej pozycji dla relative).

WłaściwośćDziałanie
top: 20px;odsuwa od górnej krawędzi (w dół)
right: 10px;odsuwa od prawej krawędzi (w lewo)
bottom: 30px;odsuwa od dolnej krawędzi (w górę)
left: 15px;odsuwa od lewej krawędzi (w prawo)
/* Przykład: element absolutny 20px od górnej i 10px od lewej krawędzi rodzica */
.box {
    position: absolute;
    top: 20px;
    left: 10px;
}

Dla relative: top: 20px przesuwa element w dół od jego normalnej pozycji.

8. z-index - warstwy (kolejność nakładania)

Właściwość z-index określa, który element znajduje się na wierzchu, gdy się nakładają. Działa tylko na elementach pozycjonowanych (nie static). Im wyższa wartość, tym wyżej. 

.div1 {
    position: absolute;
    z-index: 10;
    background: red;
}
.div2 {
    position: absolute;
    z-index: 20;  /* będzie wyżej niż div1 */
    background: blue;
}

9. overflow - co robić z nadmiarem treści

Gdy treść jest większa niż rozmiar elementu, overflow określa, czy dodać paski przewijania, przyciąć, czy pozwolić na wyjście poza element. 

/* Domyślnie overflow: visible - treść wychodzi poza ramkę */
.box1 {
    overflow: visible;
}

/* Przycinanie - treść obcięta, bez pasków */
.box2 {
    overflow: hidden;
}

/* Dodaje paski przewijania (zawsze) */
.box3 {
    overflow: scroll;
}

/* Dodaje paski tylko gdy potrzebne (najczęściej używane) */
.box4 {
    overflow: auto;
}

10. Przykład - kombinacja różnych pozycjonowań

<style>
    .card {
        position: relative;
        width: 300px;
        border: 1px solid #ddd;
        border-radius: 12px;
        overflow: hidden;
        box-shadow: 0 2px 8px rgba(0,0,0,0.1);
    }
    .card-img {
        width: 100%;
        height: 200px;
        object-fit: cover;
    }
    .badge {
        position: absolute;
        top: 10px;
        right: 10px;
        background: #e74c3c;
        color: white;
        padding: 4px 8px;
        border-radius: 20px;
        font-size: 12px;
        z-index: 2;
    }
    .card-content {
        padding: 15px;
    }
    .sticky-note {
        position: sticky;
        top: 20px;
        background: #f1c40f;
        padding: 8px;
        text-align: center;
    }
    .back-to-top {
        position: fixed;
        bottom: 20px;
        right: 20px;
        background: #2f7a67;
        color: white;
        width: 40px;
        height: 40px;
        border-radius: 50%;
        text-align: center;
        line-height: 40px;
        text-decoration: none;
        z-index: 1000;
    }
</style>

Ten przykład pokazuje: kartę z absolutną etykietą, stały przycisk "do góry" i lepką notatkę.

11. Ćwiczenia INF03

Pytanie 1: Różnica między relative a absolute?

Odpowiedź: relative pozostawia miejsce w przepływie i przesuwa względem siebie. absolute usuwa element z przepływu i pozycjonuje względem przodka pozycjonowanego.

Pytanie 2: Co to jest z-index i kiedy działa?

Odpowiedź: Określa kolejność nakładania elementów pozycjonowanych (nie static). Wyższa wartość = wyżej.

Pytanie 3: Dlaczego position: sticky nie działa, gdy nie ustawimy top?

Odpowiedź: Bo nie wiadomo, w którym momencie ma się przykleić. Potrzebuje progu.

Pytanie 4: Co zrobi overflow: hidden?

Odpowiedź: Przycina treść wychodzącą poza ramkę, nie dodaje pasków przewijania.

Rozdział CSS: Transformacje i przejścia

Transformacje i przejścia w CSS pozwalają na wprowadzanie interaktywności i płynnych zmian do elementów strony bez użycia JavaScript. To kluczowe zagadnienia przy projektowaniu nowoczesnych interfejsów użytkownika, często pojawiające się na egzaminie INF03.

1. Czym są transformacje?

Właściwość transform pozwala na zmianę kształtu, rozmiaru oraz pozycji elementu w przestrzeni dwuwymiarowej (2D) lub trójwymiarowej (3D). Transformacje nie wpływają na układ innych elementów na stronie - element jest modyfikowany wizualnie, zachowując swoje pierwotne miejsce w strukturze dokumentu.

Do podstawowych funkcji transformacji 2D należą:

  • translate() - przesunięcie elementu.
  • scale() - skalowanie (zmiana rozmiaru).
  • rotate() - obracanie elementu o określony kąt.
  • skew() - pochylenie elementu.

2. Przesunięcie - translate()

Funkcja translate(x, y) przesuwa element o podaną wartość wzdłuż osi X i Y. Możemy również użyć dedykowanych funkcji translateX(x) oraz translateY(y). 

.box {
    transform: translate(20px, 50px); /* Przesunięcie o 20px w prawo i 50px w dół */
}
.box-x {
    transform: translateX(-10%); /* Przesunięcie o 10% własnej szerokości w lewo */
}
Wartość Opis działania
translate(50px, 20px) Przesunięcie o 50px w prawo (oś X) i 20px w dół (oś Y)
translateX(100px) Przesunięcie elementu o 100px wyłącznie w poziomie
translateY(-30px) Przesunięcie elementu o 30px w górę

3. Skalowanie - scale()

Funkcja scale(x, y) pozwala na zmianę rozmiaru elementu. Wartość 1 oznacza rozmiar domyślny, wartości większe od 1 powiększają element, a mniejsze - pomniejszają go. 

.box-double {
    transform: scale(2); /* Powiększenie elementu dwukrotnie w obu osiach */
}
.box-flat {
    transform: scaleY(0.5); /* Zmniejszenie wysokości elementu o połowę */
}

4. Obrót - rotate()

Funkcja rotate(kąt) obraca element wokół punktu początkowego (domyślnie jest to jego środek). Kąt podajemy najczęściej w stopniach, używając jednostki deg. Wartości dodatnie obracają element zgodnie z ruchem wskazówek zegara, a ujemne - przeciwnie. 

.box-rotated {
    transform: rotate(45deg); /* Obrót o 45 stopni w prawo */
}
.box-rotated-left {
    transform: rotate(-90deg); /* Obrót o 90 stopni w lewo */
}

5. Przejścia - transition

Przejścia pozwalają na płynną zmianę wartości właściwości CSS w określonym czasie. Zamiast natychmiastowej zmiany (np. po najechaniu kursorem), zmiana zachodzi stopniowo.

Do zdefiniowania przejścia służą następujące właściwości składowe:

  • transition-property - określa, które właściwości mają być animowane (np. background-color, transform, all).
  • transition-duration - czas trwania przejścia (np. 0.3s, 500ms).
  • transition-timing-function - funkcja określająca tempo przejścia (np. linear, ease, ease-in-out).
  • transition-delay - opóźnienie, po którym przejście się rozpocznie.

Wygodniejszym rozwiązaniem jest stosowanie skróconego zapisu transition:

.button {
    background-color: #2f7a67;
    transition: background-color 0.3s ease-in-out;
}
.button:hover {
    background-color: #1f5e4f;
}

6. Praktyczny przykład

Poniższy element demonstruje połączenie transformacji i płynnego przejścia po najechaniu kursorem (hover).

Najedź na mnie
/* Styl podstawowy elementu */
.box {
    width: 100px;
    height: 100px;
    background-color: #2f7a67;
    transition: transform 0.3s ease, background-color 0.3s ease;
}

/* Zmiany po najechaniu kursorem */
.box:hover {
    transform: scale(1.2) rotate(10deg);
    background-color: #1f5e4f;
}

7. Co musisz zapamiętać na egzamin INF03

  • Właściwość transform służy do przekształceń geometrycznych (przesunięcie, obrót, skalowanie).
  • Właściwość transition umożliwia płynną zmianę innych właściwości w określonym czasie.
  • Dla obrotu (rotate) wartości wyrażamy w stopniach (deg), np. rotate(180deg).
  • Przejścia działają tylko wtedy, gdy zmieniana właściwość posiada wartości pośrednie (np. kolory, wymiary, przezroczystość).
